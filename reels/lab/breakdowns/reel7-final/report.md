## Разбор (заполняет Claude по кадрам)

_Заполнено ночью 2026-10-08 по листам кадров._

- Хук (визуал / голос / текст на экране): кадр 0 уже несёт всё — заголовок «ТЕМ, У КОГО / 0 НА КАРТЕ»
  (красный акцент на «0 на карте») и неоновая карта с балансом «0,00 ₽» с глитч-полосой. Голос открывает
  триггером пересылки: «Покажи это видео тому, у кого сейчас ноль на карте» — зритель становится курьером ролика.
  Текст не повторяет голос дословно, а сжимает его (правило трёхслойного хука соблюдено).
- Структура и удержание: 22 с, одна мысль на 3–4 с: боль (0 на карте) → «банки платят новичкам» →
  механика «карта → бонус» → «ещё карта → ещё бонус» (баланс растёт 0 → 500 → 1 500 → 3 000 ₽ с пушами
  «+500 ₽ бонус за первую покупку», «+1 000 ₽ приветственный бонус») → снятие страхов «0 ₽ вложений / на своё имя» →
  пост Telegram со списком → CTA. Растущий счётчик — главный двигатель досмотра.
- Графика и стиль: одна и та же карта-«герой» живёт весь ролик, меняется только её содержимое и цвет
  (красный 0 → зелёные суммы) — тот же принцип непрерывности, что в длинном ролике (`desk.js`). Заголовок сверху
  постоянный по месту, меняется текст. Субтитры по словам с подсветкой текущего слова в нижней трети. Внизу —
  дисклеймер «Суммы — пример…» (на 25 % размера не читается, но юридически присутствует).
- Переходы и монтаж: всего 2 смены сцены (средний план 7,3 с), всё остальное — изменения внутри кадра
  (счётчик, пуши, смена заголовка, глитч-проходы). Белая вспышка на 2,0 с на слове «ноль». Карта слегка
  покачивается в 3D — кадр не статичен даже без склеек.
- Звук и музыка: −14,7 LUFS, речь 2,9 слова/с без пауз > 0,5 с — плотно. По распознаванию «алоум-клиентам»
  вместо «новым клиентам» и «без уважений» вместо «без вложений» — смена тембра смазала 2 слова (та же проблема,
  что разобрана в длинном ролике 07.10: VC по входу с шумодавом хуже, чем по исходнику).
- CTA: последние ~5 с — пост канала со списком из 3 пунктов + «СПИСОК БАНКОВ В ТЕЛЕГРАМЕ / ССЫЛКА В ШАПКЕ ↑»,
  стрелка вверх анимирована. Обещание конкретное («какие банки платят сейчас и сколько»).
- Что забрать себе: (1) «герой-объект» на весь рилс вместо смены сцен; (2) растущий баланс как сюжет;
  (3) хук-пересылка «покажи тому, у кого…»; (4) переход «монета/карта → 0» по форме — см. эксперимент
  `experiments/2026-10-08-match-cut`; (5) голос для VC готовить без шумодава (урок ролика №1 YouTube).
