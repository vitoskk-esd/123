# Доработка движка — план (владелец одобрил 2026-10-08)

Цель: рилсы и YouTube привлекательнее и качественнее. Одна доработка за ночь (лаборатория, лёгкая работа,
не мешает сборке YouTube: рендер образцов с `nice -n 15`, короткие, ≤ 15 с). Утром — 10-секундное
сравнение «было / стало» (`compare.mp4`, слева было, справа стало) в утреннем сообщении. В рабочий движок
(`youtube/kit/desk.js` и др.) доработка идёт только после «да» владельца. Работа — в
`reels/lab/experiments/ГГГГ-ММ-ДД-engine-<тема>/`, правила — в навыки (retention-editing, reel-production).
Знания брать из установленных навыков (таблица стадий в youtube-longform / reel-production); после
доработки — `review-animations` по изменённому коду.

Порядок (отмечать [x] с датой и итогом):

- [ ] 0. Автопроверка ролика: детектор «мёртвых зон» (> 3 с без заметного изменения кадра — по разнице кадров
      на прореженном рендере), мелкий текст (`kit/lint_desk.js`), контраст текста к фону. Отчёт по секундам.
- [ ] 1. Объём и глубина: слой переднего плана (размытые монеты/карты проплывают мимо камеры, параллакс
      быстрее мира), «перевод фокуса» между окнами при переезде камеры (depth-of-field), фон медленнее мира.
- [ ] 2. Переходы «как в кино»: вспышка через белый, засветка плёнки (light leak), пролёт сквозь кадр
      (zoom-through, velocity-matched), цветовое расслоение. 1–2 на ролик — на раскрытии главного и на CTA.
- [ ] 3. Денежные моменты: счётчик-«слот-машина» (вертикальная прокрутка цифр), сумма растёт и увеличивается
      (counting-dynamic-scale), детерминированный взрыв монет (≤ 40 частиц), обводка числа «от руки».
- [ ] 4. Один движок для рилсов и YouTube (подробно — ниже). Делать в 2–3 ночи, по шагам.
- [ ] 5. Анимированный текст: 6–8 стилей (удар, водопад, печать, проявление из размытия, маркер, слот) для хуков
      и выводов.
- [ ] 6. Звук по картинке: свист автоматически по скорости камеры, нарастание перед раскрытием, приглушение
      музыки под голос (hyperframes-audio: voice carve / ducking).
- [ ] 7. Живой фон: декор «дышит», свечение реагирует на ударные слова голоса (≤ 4–5 % масштаба, ≤ 30 % свечения).

Отдельно от кода (просьба к владельцу, не блокирует план): 5–10 записей экрана телефона — приложения банков,
пуш о бонусе, раздел акций; личные данные блюрить при монтаже. Для рилсов — хук от первого лица.

## Пункт 4: один движок

Сейчас: YouTube — общий движок `youtube/kit/desk.js` (+ `kit/audio.js`, `render.js`). Рилсы — каждый
`reels/<NN>/reel.html` (250–380 строк) со своей копией кода анимации, своим `audio.js`, `render.js`, `voice.py`.
Улучшение в одном месте не попадает в другие.

Шаги:
1. `desk.js`/`desk.css` без жёстких 1920×1080: размер из `TL.size` (`[1920,1080]` или `[1080,1920]`), центр камеры,
   заставки, сетка фона — от размера. Пресеты формата: `long` (как сейчас) и `reel` (крупнее шрифты: заголовок
   ≥ 90 px, текст ≥ 32 px; быстрее входы; плотнее события).
2. Перенести «рилсовые» элементы из `reel.html` в общий движок как виды объектов: подписи по словам
   (только для `reel`), стикеры, punch-in, whip/glitch-переходы, вспышки.
3. Общие `kit/render.js` (параметр размера), `kit/audio.js`, голосовой конвейер (`voice_v2.py` → `kit/voice.py`),
   проверки (`lint_desk.js`, детектор из п. 0) — для обоих форматов.
4. Проверка: пересобрать рилс `zero-card-07` на общем движке, показать владельцу рядом со старым.
5. Только после «да»: новые рилсы — на общем движке. Старые рилсы не трогаем (они опубликованы).

Бонус: из каждого YouTube-ролика — вертикальные Shorts/Reels тем же движком (те же объекты, раскладка 9:16).
