# 2026-10-09 — «Типографика с массой» (пункт S1 плана «Студии»)

**Эталон.** Mat Voyce, «Think Different» — кинетическая типографика, где у букв есть вес: они оседают с инерцией, а не по
стандартной кривой ([abduzeedo](https://www.abduzeedo.com/mat-voyces-think-different-kinetic-typography-mass)). Это личный проект
по мотивам кампании Apple 1997 года, не работа Apple. Кадры Apple и Mat Voyce не скачивались — только описание и статья.

**Что сделано** (`studio_mass.js` — копия `youtube/kit/studio.js`, изменён только `S.kinetic.tick`):
- слово падает в строку по затухающей пружине (перелёт ~5 %, успокаивается за ~0,35 с) вместо «out5 за 0,5 с»;
- на перелёте слово сплющивается: scaleY −, scaleX +, точка опоры — низ строки;
- в полёте слово смазано пропорционально скорости (до 5 px), как моушн-блюр камеры;
- остальное как было: маска строки, свечение акцента, подгонка ширины.

`compare.mp4`: слева «было», справа «стало», 10 с, три сцены хука ролика №2.

**Проверка review-animations** (критерии Эмиля Ковальски в видеоконтексте):
- Цель движения есть: удар слова под голос, это объяснение, а не «красиво». Частота — только сцены kinetic, не каждый элемент.
- Только transform, opacity и filter; рендер покадровый, поэтому перерисовка не страшна. Размер шрифта теперь берётся один раз на
  сцену, а не на каждое слово в каждом кадре (было лишнее getComputedStyle).
- Длительность: оседание ~0,35 с — ближе к рекомендованным 300 мс, чем старые 0,5 с.
- Риск по характеру: пружина «живее» спокойного out5. Для хуков и ударов — да, для длинных спокойных строк лучше оставить out5.
  Предложение: пружина по флагу `s.mass` у сцены, а не везде.
- **Вердикт:** Approve для сцен-ударов при условии флага; в рабочий движок — только после «да» владельца.
