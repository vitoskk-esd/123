# 2026-10-09 — три направления для YouTube-движка

**Почему.** Владелец (09.10): «рилсы отлично, оставь… ролики для ютуб должны быть совсем иными, нужно больше функций движку».
Он выбрал «3 прототипа»: один и тот же кусок ролика №2 в трёх разных подачах, чтобы выбрать направление.

**Кусок.** Ролик №2, 2:09–2:24 (15,4 с), голос из `youtube/02-bank-earns/out/voice_final.wav`: «Главная ловушка тут — минимальный платёж.
Банк пишет: внеси полторы тысячи — и всё в порядке. Ты вносишь. Просрочки нет… а на остаток уже идут проценты, каждый день.
Минимальный платёж — это не «всё нормально». Это ты платишь банку за то, что не вернул всё.» Пример расчёта в кадре:
28 500 ₽ × 48 % ÷ 365 ≈ 37 ₽ в день, ≈ 1 125 ₽ за месяц (48 % — средняя ПСК по кредиткам, ОКБ, из таблицы источников ролика №2).

| | Направление | Как сделано | Файл |
|---|---|---|---|
| A | **Документальный** (Т—Ж, Johnny Harris) | Один большой стол-мир: договор (маркер и красная обводка «от руки»), телефон с пушем банка и оплатой, выписка со штампом «Просрочек нет» и строками «+37 ₽» по дням, карточка-вывод с зачёркиванием. Камера перелетает между предметами, моушн-блюр по скорости, глубина резкости. | `a_doc.html` |
| B | **3D-мир** (Kurzgesagt, Apple) | Одна сцена three.js: кредитка, телефон с живым экраном, стопка монет-долга. Платёж улетает из стопки в телефон, потом 30 «процентных» монет падают обратно по одной в день. PBR, тени, bloom, камера внутри сцены. | `b_3d.html` |
| C | **Ведущий-аватар** (Fomobase из референсов) | Рисованный ведущий — якорь: рот по громкости голоса, моргает, меняет эмоцию (довольный → в шоке → серьёзный). Справа окна и неоновые плашки сменяются каждые 1,5–3 с, неоновая сетка. | `c_host.html` |

Рендер: `node render.js <страница> --out out/<имя>.mp4` (локальный сервер на корень репо, WebGL через swiftshader). Сводка:
`./make_compare.sh` → `out/compare.mp4` (титр + прототип, общий голос и музыка). B считается ~5 с на кадр (≈ 40 мин на 15 с).
