# Эксперимент 2026-10-06: первый кадр — три типа хука («тест взгляда в ленте»)

Навык ночи: сценарий и хуки. Тема для проверки — «банки урезали кэшбэк» (см. `topics.md`).
Три первых кадра в нашем нейро-HUD (`hooks.html?v=A|B|C`, кадры `hook_*.jpg`) и лист `glance_sheet.jpg` —
те же кадры в 25% размера: примерно так рилс видно краем глаза в ленте и на сетке профиля.

| Вариант | Тип хука (по скилу viral-hooks) | Текст на экране | Итог на 25% |
|---|---|---|---|
| A | число в начале: «Банки урезали кэшбэк −10%» | 3 слова + число | число читается мгновенно; **график провалился**: честные −10% — это столбики почти одной высоты, конфликта не видно |
| B | потеря/узнавание: «Тебе тоже это пришло?» + стопка уведомлений | 4 слова | заголовок читается, текст уведомлений — нет (38 px → 9 px); без голоса непонятно, что пришло |
| C | контраст: «Одно урезали. Другое — нет» + две колонки ↓−10% / ✓ ЕСТЬ | 4 слова + 2 плашки | читается целиком и без звука рассказывает всю историю (потеря + надежда); **победитель** |

Выводы:
1. На 25% выживает только текст от ~90 px; всё мельче (подписи, UI) — фактура, а не смысл. Смысл кадра 0 должен держаться на 1–2 крупных элементах.
2. Маленькое число нельзя «доказывать» графиком в честном масштабе — оно выглядит как отсутствие проблемы. Число показываем крупно как цифру, график — только если разница большая.
3. Контраст «плохо / хорошо» в двух колонках — лучший кадр 0 для нашей ниши без звука: он одновременно конфликт и обещание (как статичная таблица 181× из `trends.md`).
4. Текст на экране не должен повторять голос дословно (скил viral-hooks: «sharpens, doesn't repeat»). У рилса #5 заголовок повторяет первую фразу и длиннее 7 слов — для мем-формата это норма жанра, но для остальных форматов держим 3–7 слов.

Не проверено: удержание (нужна статистика опубликованных рилсов, A/B через пробные рилсы Instagram).
