# Библиотека приёмов

| Приём | Где проверено | Итог |
|---|---|---|
| Анимации, привязанные к словам озвучки (`TIMELINE.W`) | рилсы 1–4 | основа синхрона, работает |
| Нейро-HUD: частицы + неоновая сетка (canvas), стеклянные карточки, глитч RGB на изменениях, кольцо-волна | рилс 4 | современно, владельцу нравится |
| Интерактив «ответь да/нет» + растущий счётчик | рилс 4 | ждём статистику |
| Смена тембра по кускам между паузами, лучший из N (`vc_by_phrases`) | рилс 4 | разборчивость 0.98 вместо 0.87 |
| Монтаж дублей по паузам, последний чистый дубль | рилсы 1–4 | стабильно |
| Переходы, «зашитые» в ИИ-генерацию (влёт в предмет, склейка по форме) | рилс 3 (не снят) | идея, не проверено |
| Хук-текст с кадра 0: ситуация «Когда…» или запрет «Ни в коем случае не…» | vidIQ: 8/8 залетевших в нише (2026-10-04) | не проверено у нас |
| Мем-слайдшоу под вирусный трек: статичные верх/низ, меняется центр, 1.5 с на слайд, смены на долях | vidIQ: 653×, 131× («категории кэшбэка») | не проверено |
| Контрастный панчлайн: N абсурдно высоких % → мизерный % на нужное | vidIQ: 653× | не проверено |
| Проценты руками на купюрах/муляжах (делить, рвать, перекладывать) | vidIQ: 60× (QR-код) | не проверено |
| Логическая петля: последняя фраза обрывается на «потому что…» и стыкуется с хуком | vidIQ: 60× | не проверено |
| Плашка-оффер «Товар за N ₽» по центру + серия («акция X закончилась, теперь Y») | vidIQ: 270× | не проверено |
| Скринкаст приложения: зум на нужный блок + короткие плашки-глаголы в нижней трети | vidIQ: 270× | не проверено |
| Снятие возражения внутри ролика («нет акции? → скрин в поддержку») | vidIQ: 270× | не проверено |
| Постоянный заголовок-рамка + смена «персонажа» по сценам (серия «Как банки X») | vidIQ: 112× (@56.chat) | не проверено |
| Статичная таблица-сравнение в две колонки под трек, петля | vidIQ: 181× (@nikolay.kachanov) | не проверено |
