# Библиотека приёмов

| Приём | Где проверено | Итог |
|---|---|---|
| Анимации, привязанные к словам озвучки (`TIMELINE.W`) | рилсы 1–4 | основа синхрона, работает |
| Нейро-HUD: частицы + неоновая сетка (canvas), стеклянные карточки, глитч RGB на изменениях, кольцо-волна | рилс 4 | современно, владельцу нравится |
| Интерактив «ответь да/нет» + растущий счётчик | рилс 4 | ждём статистику |
| Смена тембра по кускам между паузами, лучший из N (`vc_by_phrases`) | рилс 4 | разборчивость 0.98 вместо 0.87 |
| Монтаж дублей по паузам, последний чистый дубль | рилсы 1–4 | стабильно |
| Переходы, «зашитые» в ИИ-генерацию (влёт в предмет, склейка по форме) | рилс 3 (не снят) | идея, не проверено |
| Короткий мем-формат 8–15 с: текст-хук + смена кадра точно в бит + петля, звук — трендовый трек в приложении | vidIQ-разбор 2026-10-04 (×131) | не проверено у нас |
| Динамические субтитры по словам при «говорящей голове» / скетче | vidIQ-разбор (×112) | у нас уже есть (`renderSubs`) |
