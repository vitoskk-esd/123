# Рилс #7 «0 на карте» (в работе)

Тема из ночной подборки 2026-10-07 (`reels/lab/topics.md`): хук «покажи это тем, у кого 0 на карте» — у двух авторов
1553× и 597× к медиане (vidIQ). Наш вариант: красный баланс «0,00 ₽» на голографической карте → банки платят новичкам →
оформил + покупка → бонус → ещё бонусы, баланс растёт → «0 ₽ вложений / на своё имя / законно» → список банков в Telegram.

## Сценарий (голос владельца, ~23 с; фразы цельные — урок рилса #5)

| # | Голос | На экране |
|---|---|---|
| 0 | Покажи это видео тому, у кого сейчас ноль на карте. | кадр 0: «Тем, у кого 0 на карте», карта с красным «0,00 ₽» (глитч) |
| 1 | Банки сами платят новым клиентам за оформление карты. | «Банки платят новичкам» |
| 2 | Оформил дебетовую, сделал одну покупку, и пришёл бонус. | шаги «1 · оформил», «2 · покупка», уведомление «+500 ₽», баланс зеленеет |
| 3 | Ещё одна карта, ещё один бонус. И так в нескольких банках. | «+1 000 ₽», «+1 500 ₽», баланс до 3 000 ₽ |
| 4 | Без вложений, на своё имя и полностью законно. | три галочки |
| 5 | Какие банки платят сейчас и сколько, собрал в телеграме. Ссылка в шапке профиля. | пост Telegram, «ссылка в шапке ↑», петля к «0,00 ₽» |

Суммы на экране — пример (диапазон бонусов за дебетовые карты 500–2 000 ₽ — Mail.ru Финансы, 2026), внизу дисклеймер.
Банки не называются. Темп музыки — параметр `BPM` в `audio.js`, после записи подобрать по
`reels/lab/experiments/2026-10-07-beat-grid/beat_grid.js`.
