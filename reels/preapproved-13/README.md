## Факты (веб-поиск 12.10.2026; перед озвучкой сверить ещё раз)

- «Предодобрено» ≠ одобрено: массовый оффер «основан на общих данных и имеет исключительно маркетинговый характер»; окончательное
  решение — после проверки долговой нагрузки и данных бюро кредитных историй
  ([Совкомбанк, журнал](https://journal.sovcombank.ru/krediti/bank-predvaritelno-odobril-kredit--chto-eto-znachit),
  [ВТБ](https://www.vtb.ru/articles/kreditnye-karty/chto-znachit-predodobrena-kreditnaya-karta/)).
- Заявка → банк запрашивает кредитную историю; сведения о заявках хранятся в кредитной истории (218-ФЗ «О кредитных историях» —
  информационная часть; **проверить формулировку по тексту закона перед озвучкой**).
- «Много заявок подряд — тревожный сигнал» — общая практика скоринга, без цифр; в кадре без процентов и «баллов».
