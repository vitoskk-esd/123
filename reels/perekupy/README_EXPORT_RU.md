# «Перекупы» — как делать такие же мультролики (рилсы 9:16)

Это полный набор, которым собраны серии «Толян: свой автосалон»: движок мультфильма, персонажи, вырезки машин, озвучка, проверка
речи, рендер, варианты b/c/h, правила владельца и готовая 21-я серия как образец.

**Главное, что нужно знать:** видео собирается **кодом** (HTML-сцены → кадры в браузере → mp4). Поэтому нейросеть должна уметь
**запускать команды на компьютере**: Claude Code, Codex CLI, Cursor/Windsurf в режиме агента, Aider и т. п.
Обычный чат (ChatGPT/Gemini в браузере без доступа к терминалу) напишет сценарий и код сцен, но сам ролик не отрендерит.

---

Сделай следующую серию по образцу `reels/perekupy/toon/series73` (21-я серия). Сначала карусель, видео — после моего «собирай».»

## 2. Что нужно установить (Linux или macOS; на Windows — через WSL)

- **Node.js 18+** и **Playwright с Chromium**: `npm i -g playwright && npx playwright install chromium`
  (рендер ищет `require('playwright')`; если стоит локально — запускать из папки, где он установлен, или `NODE_PATH`).
- **Python 3.10+** и виртуальное окружение: `bash reels/perekupy/toon/setup_env.sh` (ставит faster-whisper, numpy, scipy, pillow
  в `~/reels-venv`). Дальше во всех командах `PY=~/reels-venv/bin/python`.
- **ffmpeg** (`apt-get install ffmpeg` / `brew install ffmpeg`).
- Модели Whisper (small, medium ≈ 1,5 ГБ) скачаются сами при первой проверке речи.

## 3. Ключи для озвучки

Озвучка — Google Gemini TTS (модель `gemini-3.1-flash-tts-preview`), запасной путь — OpenRouter.
Ключи **не пиши в код и не вставляй в чат с нейросетью** — задай их переменными окружения в своём терминале:

```bash
export GEMINI_API_KEY="…"        # ключ из Google AI Studio (aistudio.google.com → Get API key)
export OPENROUTER_API_KEY="…"    # необязательно: запасной, если у Gemini кончилась суточная квота
```

`tts_pairs.py` сам подставит их в запросы. `TTS=gemini` — только Google, `TTS=openrouter` — только OpenRouter, по умолчанию — авто.

## 4. Проверка, что всё работает (без ключей)

Образец 21-й серии уже озвучен (`series73/vo/ep82/`), поэтому его можно собрать сразу:

```bash
cd reels/perekupy/toon/series73
python3 build2.py ep82                                              # сцены → ep82.html
node ../../kit/render.js ep82.html stills 0.05,12,25,40,63 st       # 5 кадров в папку st/
MUSIC_VOL=0 PY=~/reels-venv/bin/python bash make2.sh ep82           # полный ролик → final/perekupy_ep82.mp4 (~5–10 мин)
PY=~/reels-venv/bin/python python3 fast_variants.py ep82            # варианты b/c/h
```

## 5. Как сделать новую серию (порядок владельца)

1. **Папка серии** — копия последней:
   ```bash
   cd reels/perekupy/toon && mkdir series74 && cd series73
   cp shoot.js props.js base.tpl.html common.css common.js make2.sh place2.py build2.py fast_variants.py masks.css ../series74/
   cd ../series74 && sed -i 's/props82/props83/g' build2.py
   ```
   **Сразу поправь `fast_variants.py`**: номер серии и три подзаголовка вариантов b/c/h (иначе варианты выйдут с плашкой прошлой серии).
2. **Фоны** — `../gen_bgs75.py` по образцу `gen_bgs74.py`: 3 новых SVG-фона 1080×1920, имена не должны повторяться
   (`ls ../bg_*.svg.part`). Затем `bgs.js`:
   ```bash
   python3 -c "import json;n=('фон1','фон2','фон3');open('bgs.js','w').write('window.BGS='+json.dumps({k:open(f'../bg_{k}.svg.part').read() for k in n},ensure_ascii=False)+';\n')"
   ```
3. **Реквизит** `props83.js` по образцу `props82.js`: новые герои (перекраска `ch("perekup", …)` / `ch("vika", …)`), карточки бота
   (`BOTH` + `CARD`), 2–4 новых приёма (вставки на весь экран, штампы, счётчики), машины из `../../kit/img/`.
4. **Карусель** `board.html` (5 слайдов A/B с текстом озвучки и описанием) → `node shoot.js board.html 5 board` → показать владельцу.
   **Видео — только после «собирай».**
5. **Сценарий** `ep83.json` (≈15 реплик, итог 1:05–1:15, `pause` — пауза ПЕРЕД репликой) и `voices.json` (голос, темп, профиль героя).
6. **Озвучка**: `$PY ../tts_pairs.py ep83 && $PY place2.py ep83 && python3 ../voice_qa.py ep83` — смотри распознанный текст
   и шум. Слово распознаётся криво — **переформулируй реплику** и переозвучь (удали `vo/pair_<герои>.wav`).
7. **Сцены** `ep83.js` по образцу `ep82.js` → `python3 build2.py ep83` → кадры `node ../../kit/render.js ep83.html stills … st` → смотри глазами.
8. **Рендер**: `MUSIC_VOL=0 PY=$PY bash make2.sh ep83`, потом `PY=$PY python3 fast_variants.py ep83`.
9. **Проверка перед отправкой**: Whisper medium по финальному звуку, громкость ≈ −14 LUFS, кадр 0 всех четырёх mp4 (правильный номер!),
   последний кадр — только карточка бота.

## 7. Что нейросеть должна помнить (самое частое)

- Кадр 0: герой с телефоном, на экране карточка бота + плашка «ТОЛЯН · N: …» (видна с первого кадра, гаснет к 1,6 с).
- Говорящий всегда в кадре (или в кружке PIP). Последняя реплика — продающая фраза Лиса про бота, каждый раз новыми словами;
  последний кадр — только карточка бота.
- Каждая серия: новые фоны, новые второстепенные герои, 2–4 новых приёма. Сезон «Свой автосалон» — без мата.
- Вырезки машин: без тени под кузовом, все колёса целые, без белых клочков.
- Числа в озвучке — словами; трудные слова проверять отдельно (Whisper small и medium) и переформулировать.
- Звук нейросеть не слышит — проверяет распознаванием; финал всё равно послушай сам.
