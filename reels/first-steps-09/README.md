# Рилс #9 «18 лет, 0 ₽: первые 3 шага, чтобы банки платили тебе»

Тема выбрана владельцем 09.10 (вариант 2 из списка). Первый рилс на движке «Студия» в формате 9:16
(`youtube/kit/studio.js`, `TL.size = [1080, 1920]`, субтитры по словам). Порядок шагов и цифры — из ролика №2
(`youtube/02-bank-earns/script.md`, таблица источников).

## Сценарий (~35–40 с; голос «E» — без записи владельца, фразы — `phrases.txt`)

| # | Голос | На экране («Студия», 9:16) |
|---|---|---|
| 0 | Если бы мне снова было восемнадцать и на карте было ноль рублей, я бы начал с этих трёх шагов. И банки платили бы мне, а не наоборот. | кадр 0: «18 лет · 0 ₽» огромно + «3 шага, чтобы банки платили тебе»; счётчик баланса «0 ₽» |
| 1 | Шаг первый: дебетовая карта с бонусом за первые покупки. Кредитного риска нет вообще, а банк платит просто за то, что ты пришёл. | 3D-карта, номер «1» + «Дебетовая с бонусом»; плашка «риск: 0»; пуш «+ бонус за первую покупку» |
| 2 | Шаг второй: накопительный счёт с приветственной ставкой. Новичкам банки платят больше, чем своим, так что деньги не должны спать на нуле. | номер «2» + «Накопительный счёт»; столбики «на карте 0 %» / «приветственная до 15,5 %» (пример, условия на 30.09) |
| 3 | Шаг третий, и только потом: кредитка. Когда ты уверен, что вернёшь всё до конца льготного периода. Иначе заплатишь почти пятьдесят процентов годовых. | номер «3» + «Кредитка — последней»; календарь льготного периода; штамп «48 % годовых» (средняя ПСК, ОКБ) |
| 4 | Какие банки платят новичкам прямо сейчас, я собираю в своём телеграме — он у меня в профиле. Отправь это другу, которому восемнадцать. | список «1 · Дебетовая → 2 · Накопительный → 3 · Кредитка»; карточка Telegram «в профиле ↑» |

Внизу мелко (≥ 24 px): «Условия зависят от банка и акции. Не реклама конкретного банка». Банки не называются.

**Факты.** Средняя полная стоимость кредитки 48 % и выше — ОКБ, 2026. Приветственная ставка 15,5 % на 3 месяца — пример
(«Халва» Совкомбанка, Т—Ж, 30.09.2026; в ролике банк не называем). Бонус за первые покупки по дебетовой — без кредитного
риска, условия акции свои у каждого банка.
