# Рилс #5 «Категории кэшбэка»

Мем-формат сезона в нашем нейро-HUD: банк «подобрал» абсурдные категории кэшбэка,
владелец с каменным лицом комментирует каждую, в конце — «Продукты 0,01%» и поворот
«а если без шуток — где кэшбэк реально есть, в телеграме».

Почему эта тема: в выборке vidIQ от 2026-10-04 три независимых ролика про категории кэшбэка —
1,1 млн (653× к медиане автора), 2 млн (131×), 3,8 млн у скетча (`reels/lab/trends.md`).

## Файлы

- `voice.py` — запись владельца → чистка → тембр «вариант 5» по фразам (`vc_by_phrases`) → `timeline.js`.
  Сценарий и категории (`cats`, `punch` в `TEMPLATE`) правятся здесь.
- `timeline.js` — сгенерирован: сцена 0 — хук, 1–7 — категории, 8 — «Продукты», 9 — поворот и CTA.
- `reel.html` — композиция: мем-заголовок с кадра 0, панель «приложения банка», карточки со свайпом,
  удар с глитчем и штампом, Telegram-пост, петля (последние 0,35 с возвращают первый кадр).
- `audio.js` — музыка и SFX; `NO_MUSIC=1` — только SFX (версия под трендовый трек в Instagram).
- `storyboard.jpg` — раскадровка, согласованная с владельцем до сборки.

## Сборка

```bash
VOICE_REC=my_voice_script.m4a VOICE_FX=vc <python-с-chatterbox> voice.py
node audio.js && NO_MUSIC=1 node audio.js && node render.js
# reel_final.mp4 (своя музыка) и reel_final_no_music.mp4 (голос + SFX) — см. build.sh
```

Запись владельца (`my_voice*`) в репозиторий не коммитится.
