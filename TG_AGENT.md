# Telegram-ассистент для роста канала

Работает через **ваш** аккаунт Telegram (Telethon) и Claude.
Оставляет экспертные комментарии под постами каналов, на которые вы подписаны.

## Как это работает

1. В канале выходит пост с открытыми комментариями.
2. Ассистент ставит его в очередь и ждёт **случайные 3–5 минут**.
3. Затем перечитывает пост (его могли отредактировать или удалить) и решает, есть ли
   что добавить как эксперту. Рекламу, розыгрыши и темы не из вашей ниши он пропускает.
4. Пишет комментарий строго по содержанию поста: цепляется за конкретный тезис и
   добавляет нюанс из практики, аргументированное несогласие или точный вопрос.
   Ссылок и «подписывайтесь» нет: интерес вызывает экспертность, и люди сами
   открывают ваш профиль.
5. Публикует комментарий и присылает вам в «Избранное» отчёт со ссылкой, чтобы вы
   видели, что написано от вашего имени, и могли удалить неудачный комментарий.

## Защита от бана

| Настройка | По умолчанию | Зачем |
|---|---|---|
| `TG_DELAY_MIN_MINUTES` / `TG_DELAY_MAX_MINUTES` | 3–5 мин | комментарий не в ту же секунду, что пост |
| `TG_GAP_MIN_MINUTES` / `TG_GAP_MAX_MINUTES` | 2–4 мин | если несколько постов вышли одновременно, комментарии не уйдут пачкой |
| `TG_MAX_COMMENTS_PER_DAY` | 15 | Telegram ограничивает аккаунты, которые много пишут |
| фильтр «есть ли что сказать» | всегда | пустые комментарии под каждым постом выглядят как спам, и админы банят за них |

Если в каком-то канале писать нельзя (бан, закрытые комментарии), ассистент перестаёт
туда писать до перезапуска. На `FloodWait` от Telegram он ждёт столько, сколько попросили.

Начните с небольшого лимита (5–10 в день) и постепенно увеличивайте. Резкий старт
с новым поведением аккаунта рискованнее, чем ровная активность.

## Чтобы комментарии приводили в канал

Комментарий вызывает интерес, а дальше человек открывает ваш профиль. Подготовьте его:
- **Личный канал в профиле:** Настройки → Мой аккаунт → Личный канал. Тогда канал
  виден прямо в профиле.
- **Имя и био:** понятно, кто вы и чем полезны, например «Внедряю ИИ-агентов в бизнес · кейсы в канале».
- **Аватар** с лицом: живому человеку доверяют больше.
- В `TG_PERSONA` подробно опишите свою экспертизу: чем точнее описание, тем увереннее
  и предметнее комментарии.
- Подпишитесь на каналы своей ниши: ассистент комментирует только их.

## Запуск

Нужны Python 3.10+ и ключ Anthropic API (тот же `ANTHROPIC_API_KEY`, что у kwork_agent).

```bash
pip install -r requirements.txt
cp .env.example .env        # впишите ANTHROPIC_API_KEY, TG_API_ID, TG_API_HASH, TG_MY_CHANNEL, TG_PERSONA
python -m tg_agent login    # номер телефона + код из Telegram (один раз)
python -m tg_agent run      # работает, пока запущен
python -m tg_agent status   # сколько комментариев сегодня и последние из них
```

`TG_API_ID` и `TG_API_HASH` выдаются на https://my.telegram.org → API development tools.

Ассистент должен быть запущен постоянно, чтобы видеть новые посты: на своём компьютере,
VPS или любом сервере (`nohup python -m tg_agent run &` или systemd). GitHub Actions
для этого не подходит: там нет постоянного процесса. Очередь хранится в памяти: если
перезапустить ассистента, пока комментарий ждёт своих 3–5 минут, этот пост останется
без комментария.

**Безопасность:** файл `data/tg/account.session` даёт полный доступ к вашему аккаунту.
Он в `.gitignore`: никогда не коммитьте его и никому не передавайте.
