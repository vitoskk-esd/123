# Telegram-ассистент для роста канала

Работает через **ваш** аккаунт Telegram (Telethon) и Claude.

## Что он делает

1. **Комментарии к постам.** Когда в канале, на который вы подписаны, выходит пост
   с открытыми комментариями, ассистент читает его и решает, есть ли что добавить
   как эксперту. Если есть, он пишет комментарий строго по содержанию поста:
   зацепка за конкретный тезис, неочевидный нюанс из практики или точный вопрос.
   Никаких ссылок и «подписывайтесь»: люди открывают профиль, потому что вы
   выглядите как человек, который разбирается в теме. Рекламу, розыгрыши и посты
   не по вашей нише он пропускает сам.
2. **Ответы в чатах.** В личке, в группах, где вас упомянули или ответили на ваше
   сообщение (в том числе в ветках под вашими комментариями), и в группах из
   `TG_WATCH_GROUPS` он пишет ответ с учётом всей истории этого чата.
3. **Память.** Для каждого чата хранятся последние 40 сообщений дословно и
   резюме всего, что было раньше: кто участники, о чём договорились, какие вопросы
   открыты. Ваши собственные сообщения тоже попадают в память. Всё лежит в `data/tg/chats/`.
4. **Учится вашему стилю.** Если вы присылаете свой текст вместо черновика, пара
   «черновик → ваш вариант» сохраняется, и следующие черновики пишутся ближе к вашей манере.

## Вы утверждаете каждую публикацию

Сам по себе ассистент ничего не отправляет. Каждый черновик приходит вам в
**«Избранное»** со ссылкой на пост или чат. Ответьте на черновик (свайп → ответить):

| Ответ | Что произойдёт |
|---|---|
| `+` | опубликовать как есть |
| `-` | пропустить |
| `заново` | написать другой вариант |
| любой текст | опубликовать ваш текст (правка запоминается) |

Почему так:
- Массовые автокомментарии и автоответы — прямой путь к бану: Telegram ограничивает
  аккаунты за спам, а админы каналов банят комментаторов-ботов. Решение в одно касание
  плюс дневной лимит (`TG_MAX_COMMENTS_PER_DAY`, по умолчанию 15) защищают аккаунт.
- Люди в чатах уверены, что говорят с вами. Если от вашего имени отвечает модель,
  а вы этого не видите, рано или поздно она пообещает что-то не то или выдумает факт.
  С утверждением каждое сообщение — по-прежнему ваше.
- Утверждать быстро: на черновик уходит пара секунд, всю работу по чтению и
  формулировке ассистент уже сделал.

## Чтобы комментарии приводили в канал

Комментарий вызывает интерес, а дальше человек открывает ваш профиль. Подготовьте его:
- **Личный канал в профиле:** Настройки → Мой аккаунт → Личный канал. Тогда канал
  виден прямо в профиле.
- **Имя и био:** понятно, кто вы и чем полезны, например «Внедряю ИИ-агентов в бизнес · кейсы в канале».
- **Аватар** с лицом: живому человеку доверяют больше.
- В `TG_PERSONA` подробно опишите свою экспертизу: чем точнее описание, тем увереннее
  и предметнее комментарии.

## Запуск

Нужны Python 3.10+ и ключ Anthropic API (тот же `ANTHROPIC_API_KEY`, что у kwork_agent).

```bash
pip install -r requirements.txt
cp .env.example .env        # впишите ANTHROPIC_API_KEY, TG_API_ID, TG_API_HASH, TG_MY_CHANNEL, TG_PERSONA
python -m tg_agent login    # номер телефона + код из Telegram (один раз)
python -m tg_agent run      # работает, пока запущен; черновики приходят в «Избранное»
python -m tg_agent status   # лимит, черновики, память
```

`TG_API_ID` и `TG_API_HASH` выдаются на https://my.telegram.org → API development tools.

Ассистент должен быть запущен постоянно, чтобы видеть новые посты: на своём компьютере,
VPS или любом сервере (`nohup python -m tg_agent run &` или systemd). GitHub Actions
для этого не подходит: там нет постоянного процесса.

**Безопасность:** файл `data/tg/account.session` даёт полный доступ к вашему аккаунту.
Он в `.gitignore`: никогда не коммитьте его и никому не передавайте.
