# «Перехват» — бот для перекупов

Человек пишет боту, что ищет («камри от 2012 до 1,2 млн, Москва, без битых»). Бот следит за Telegram-каналами,
где продают машины, и присылает подходящие через секунды после публикации:
- без дублей;
- с оценкой «на сколько ниже рынка»;
- с метками «срочно», «торг», «битая» и предупреждением о мошенниках.

Подписка — 990 ₽ на 30 дней, первые 3 дня бесплатно.

## Как запустить на своём компьютере
1. **Python.** Поставь Python с python.org. На Windows при установке отметь галочку «Add python.exe to PATH».
2. **Ключи служебного аккаунта.** Возьми отдельный Telegram-аккаунт, не личный: он будет читать каналы. Зайди с него
   на **my.telegram.org** → API development tools → создай приложение с любым названием. Запомни **api_id** и
   **api_hash**.
3. **Первый запуск.** Дважды кликни **«Запуск (Mac).command»** или **«Запуск (Windows).bat»**. Откроется файл
   настроек. Впиши три строки — `BOT_TOKEN` (от @BotFather), `TG_API_ID`, `TG_API_HASH` — сохрани и запусти файл
   снова. Если Mac пишет «не удаётся проверить разработчика»: правый клик по файлу → «Открыть».
4. **Вход в служебный аккаунт.** Окно попросит номер телефона служебного аккаунта и код из Telegram. Это нужно один
   раз.
5. **Проверка.** Напиши своему боту `/start`. Кто написал первым, тот и админ. Добавь каналы: `/add @канал1 @канал2`.

Бот работает, пока открыто окно и компьютер не спит.

## Команды админа
- `/admin` — цифры: люди, оплаты, посты за сутки, средняя задержка.
- `/add @канал1 t.me/канал2 t.me/+приглашение` — добавить каналы в общую базу. Подключаются по одному раз в 90 с,
  чтобы Telegram не заблокировал аккаунт.
- `/list` — каналы и их статус. `/del @канал` — убрать канал.
- `/broadcast текст` — написать всем.

## Оплата
Пока в `.env` не вписаны ключи ЮKassa (`YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`), бот бесплатный для всех. Это удобно,
чтобы попробовать. Впишешь ключи — включатся 3 бесплатных дня и подписка 990 ₽.

## Что где лежит
- `cars.yaml` — марки, модели, города, слова-маркеры. Можно дописывать.
- `bot/texts.py` — все тексты бота.
- `bot/` — код, `tests/` — проверки (`python -m pytest`).

## Важно
- Служебный аккаунт — отдельный номер. Если Telegram что-то не понравится, заблокирует его, а не твой личный.
- Telegram пропускает около 30 сообщений в секунду. Если на одну машину подошло 300 человек, последние получат её
  примерно через 10 секунд.
- Для работы круглосуточно нужен сервер. Лучше за пределами РФ (Нидерланды или Финляндия): там серверы Telegram,
  задержка меньше.
