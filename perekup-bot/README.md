# «Перехват» — бот для перекупов: машины из Telegram-каналов через секунды после публикации

Человек пишет обычными словами, что ищет («камри от 2012 до 1,2 млн, Москва, без битых»). Бот следит за общей
базой каналов и за каналами, которые человек добавил сам, и присылает подходящие посты раньше остальных.

Подписка — 990 ₽ / 30 дней, первые 3 дня бесплатно. Только РФ.

## Что получает человек
| | |
|---|---|
| ⚡ **Скорость** | Пост в канале → карточка в боте за секунды. На карточке видно, сколько прошло: «⏱ 2,4 с». |
| 🔎 **Фильтр словами** | Марки и модели (37 марок, 238 моделей с народными названиями: «солярис», «крузак», «приору»), годы, бюджет, пробег, города, «без битых / такси / кредитных», свои стоп-слова, «только ниже рынка на 15%». |
| 📢 **Каналы** | Общая база — каждый может отключить у себя ненужные. Свои каналы и чаты по ссылке, в том числе закрытые по приглашению: их видит только тот, кто добавил. |
| ♻️ **Без дублей** | Одна машина из пяти каналов приходит один раз: тот же текст (без ссылок, ников и телефонов) или та же марка-модель-год-цена-пробег, переписанная другими словами. |
| 🔥 **Ниже рынка** | Бот сам копит цены из всех постов. Цена рынка — медиана той же модели ±1 год за 90 дней, минимум 5 объявлений, без дублей и без битых. Чем дольше бот работает, тем точнее оценка. |
| 🏷 **Слова-маркеры** | ⚡ срочно, торг, переезд, 1 владелец · ❗ битая, на запчасти, не на ходу, требует вложений, дубликат ПТС, кредит/залог, такси · «не требует вложений» и «без ДТП» маркерами не считаются. |
| ⚠️ **Мошенники** | Цена на 45%+ ниже рынка или «дистанционное оформление», «доставка в любой регион», «предоплата», «новые регионы» — предупреждение на карточке. После роста утильсбора таких каналов стало много. |
| 📊 **Статистика** | Сколько машин пришло за 7 и 30 дней, сколько ниже рынка на 10%+ и 20%+, средняя и лучшая скорость, сколько дублей отсеяно, из каких каналов больше всего. По понедельникам — итоги недели. |

Рассылка всем подходящим одновременно: никаких приоритетов и мест на город.

## Как это устроено и почему быстро
```
канал ──(мгновенно, без опроса)──► служебный аккаунт Telegram (Telethon)
                                     │ разбор правилами: ~0,25 мс на пост
                                     │ если правила не нашли модель или цену — ИИ (Gemini lite, ~1 с, таймаут 4 с)
                                     │ дубль? цена рынка? кому подходит? — локальная SQLite
                                     ▼
                       бот ──► всем подходящим сразу: карточка (−X% к рынку, цена, маркеры, ссылка на пост)
                         └──► следом сам пост с фото: служебный аккаунт пересылает его в буферный канал,
                              бот копирует оттуда — фото заново не загружаются
```
Обычный бот Telegram не может читать чужие каналы, поэтому посты читает отдельный аккаунт.

**Замер** (`tests` + отдельный прогон): 5 000 человек с фильтрами, на пост подошло 1 463. Своя обработка бота до
первой карточки — **71 мс**. Остальное время — сеть Telegram и его лимиты.

**Лимит Telegram — около 30 сообщений в секунду на бота.** Если на одну машину подходит 30 человек — все получат её
примерно в одну секунду. Если 300 — последние будут ждать около 10 секунд. Когда подписчиков станет много, включи
`PAID_BROADCAST=1`. Это платная рассылка Telegram до 1000 сообщений в секунду: сверх бесплатного лимита она
списывает звёзды с баланса бота.

## Запуск (≈30 минут)
Нужно: сервер, работающий круглосуточно (1 ядро, 1 ГБ хватит), Ubuntu, Python 3.11+.
**Сервер лучше взять за пределами РФ, ближе к Амстердаму (Нидерланды, Финляндия)**: там серверы Telegram, а в РФ
Telegram бывает замедлен. От этого напрямую зависит задержка.

1. **Бот.** @BotFather → `/newbot` → токен. Свой id узнай у @userinfobot.
2. **Служебный аккаунт.** Отдельный аккаунт Telegram на отдельный номер, не личный: при нарушениях Telegram
   блокирует именно его. Зайди с него на my.telegram.org → API development tools → получи `api_id` и `api_hash`.
3. **Буферный канал.** Создай закрытый канал (например, «Перехват буфер»). Добавь в админы служебный аккаунт и
   бота. Id канала (вида `-1001234567890`) узнай: перешли сообщение из канала боту @getidsbot.
4. **ЮKassa** (yookassa.ru → Интеграция → Ключи API) и ссылка на оферту. Автопродление (`YOOKASSA_AUTOPAY=1`)
   работает, только если в ЮKassa включены рекуррентные платежи. Пока их нет, бот присылает ссылку на оплату перед
   концом доступа.
5. На сервере:
   ```bash
   apt update && apt install -y python3-venv git
   useradd -m perekup && mkdir -p /opt/perekup-bot && cd /opt/perekup-bot
   # скопируй сюда папку perekup-bot (git clone репозитория или scp)
   python3 -m venv venv && venv/bin/pip install -r requirements.txt
   cp .env.example .env && nano .env          # токен, ADMIN_IDS, TG_API_ID/HASH, BUFFER_CHANNEL_ID, ЮKassa
   venv/bin/python -m bot login main          # один раз: телефон служебного аккаунта и код из Telegram
   chown -R perekup /opt/perekup-bot
   cp deploy/perekup-bot.service /etc/systemd/system/ && systemctl enable --now perekup-bot
   journalctl -u perekup-bot -f               # лог; Ctrl+C — выйти
   ```
6. **Общая база каналов.** Есть два способа:
   - в боте: `/addbase @канал1 https://t.me/канал2 t.me/+приглашение msk` (последнее слово — код региона, если все
     каналы из одного города);
   - списком в `channels.yaml` — бот подхватит его при запуске.

   Каналы подключаются по одному раз в 90 с, чтобы Telegram не заблокировал аккаунт. Ход подключения видно в `/base`.
7. Напиши боту `/start`, создай фильтр, потом `/admin`.

**Больше 480 каналов.** Добавь второй служебный аккаунт (`TG_SESSIONS=main,second`, затем
`python -m bot login second`). Новые каналы сами пойдут на менее загруженный.

## Админка (только ADMIN_IDS)
- `/admin`:
  - люди, пробный период, платят сейчас, MRR, выручка за 30 дней, отток;
  - посты за сутки: машины, дубли, разобрано ИИ, средняя задержка;
  - каналы и загрузка аккаунтов;
  - источники (`t.me/<бот>?start=reels` → источник `reels`).
- `/addbase …` — каналы в общую базу. `/base` — список, статус, число постов, ошибки. `/delbase @канал` — убрать канал совсем.
- `/broadcast текст` — рассылка всем. Или ответь `/broadcast` на сообщение, и бот разошлёт его копию.
- `/grant <id> <дней>` — выдать доступ вручную. `/reload` — перечитать `cars.yaml` после правки.

## Что правится без программиста
- `cars.yaml`:
  - марки и модели с народными названиями;
  - регионы с городами области;
  - слова-маркеры с видом (good / bad / scam).
- `bot/texts.py` — все тексты бота.
- `.env` — цена, дни подписки, пробный период, лимиты фильтров и своих каналов.

## Проверено
`python -m pytest`: 23 теста.
- **Разбор постов.** 10 постов в реальных форматах: эмодзи, сокращения «790к», «140т.км», «2,9 млн», «цена 270»,
  телефоны, латиница внутри русских слов, цены в тенге, «Пробег 97-000», падежи «Ниву», «Лады Весты».
- **Ловушки цены.** Пробег и телефон — не цена, «452 000» — не модель «Буханка».
- **Маркеры и отрицания.** «Не требует вложений» и «без ДТП» маркерами не считаются.
- **Дубли** по тексту и по машине.
- **Фильтры словами** и все условия совпадения.
- **Рынок:** медиана, минимум объявлений.
- **Сквозные сценарии через диспетчер aiogram без Telegram:**
  - фильтр → 5 постов учат рынок → пост «−17% к рынку» с маркерами и фото из буфера;
  - та же машина из другого канала не приходит повторно;
  - мошенник с предупреждением и текстом поста, когда пересылка запрещена;
  - свой канал видит только добавивший, отключённый канал из базы не присылает;
  - без доступа машины копятся в «пропущено» → оплата → снова приходят, двойное «Я оплатил» не продлевает дважды;
  - напоминание о конце пробного периода уходит один раз;
  - вступление служебного аккаунта в канал из очереди и уведомление человеку.

**Не проверено:** живой Telegram и живая ЮKassa — для них нужны токен бота, служебный аккаунт и ключи магазина.
Запускай сначала на паре своих каналов и сверяй задержку в `/admin`.

## Риски — прочитай до запуска
- **Служебный аккаунт.** Чтение каналов через пользовательский аккаунт Telegram допускает, но за массовые
  вступления и спам блокирует. Отдельный номер, вступления с паузой, не больше ~480 каналов на аккаунт.
- **Чужой контент.** Бот пересылает посты каналов подписчикам со ссылкой на источник. Если владелец канала
  попросит — убери канал: `/delbase @канал`.
- **Персональные данные.** Бот хранит только Telegram id, ник и платежи. Контакты продавцов остаются в
  пересланных постах.
- **Оплата.** Для ЮKassa нужны оферта и чеки (54-ФЗ). Для самозанятого чеки можно делать через «Мой налог».
- **Оценка рынка — ориентир, а не экспертиза.** Медиана по объявлениям из каналов, а не по сделкам.
