# Рилс-история в моушн-дизайне (референс владельца, 28.10)

Референс: запись экрана Instagram, 36,7 с, тема — прокрастинация монтажёра («40 сохранённых уроков, 0 роликов»).
Разбор: кадры fps=1, крупные кадры, Whisper small по словам. Сделан кодом (HTML-моушн): в рамке видны служебные
подписи «ЗАП 00:00:01:28 · КАДР 0058 / 1461 · 01 / 13 — СОРОК УРОКОВ · 1080 × 1920 · 30 К/С».

## Цифры
| | Референс |
|---|---|
| Длина | 36,7 с, 89 слов, **2,5 слова/с** |
| Склейки | **ни одной** (детектор сцен: 2 «перехода» по 6 кадров — это морфы внутри холста) |
| Главы | 13 «глав» за 36 с → **~2,8 с на мысль**, номер главы и полоса прогресса внизу |
| Текст | почти на каждой фразе 1–4 слова крупно, синхронно со словом |
| Цвета | фон почти чёрный (#0F1011), белый, один кислотный акцент (лайм ≈ #C6F01E) |
| Шрифты | широкий тяжёлый гротеск капсом (типа Unbounded Black); мелкий моно для служебных подписей |

## Почему это работает (переносим это, а не картинку)
1. **История, а не совет.** Монолог от первого лица про узнаваемую боль, с самоиронией и живой речью (мат, «очень удобно»).
   Развязка — честный вывод про себя («хочу перестать требовать от первого черновика…»). Зритель узнаёт себя → пересылает.
2. **Счётчик как сюжет.** В шапке всё время «СОХРАНЕНО 40 · СОЗДАНО 0»; по ходу «40 → 41», «создано» так и остаётся 0.
   Одна цифра рассказывает историю без слов.
3. **На каждую фразу — свой образ, а не просто текст:** список сохранённых уроков-карточек; стикер «ОХУЕННЫЙ РОЛИК» шлёпается
   поверх; окно нейросети «Что создадим сегодня?» и курсор нажимает; стикеры-отговорки «СНАЧАЛА РАЗОБРАТЬСЯ / НУЖЕН ПЛАН /
   ПОЗЖЕ» налепляются стопкой; **кольцо из текста «сначала → потом → когда будет время» крутится** (замкнутый круг);
   кнопка паузы с курсором («даже отдыхать…»); сетка плиток «готовлюсь» прогибается; пустая карточка «ЧЕРНОВИК 01»,
   над ней проявляется «ЛУЧШАЯ РАБОТА В МОЕЙ ЖИЗНИ».
4. **Один холст.** Элементы перетекают из одного в другое (карточка → окно → кольцо → плитки), камера не режется.
   Ощущение дорогого моушна, а не слайдов.
5. **Рамка «монитора режиссёра»:** уголки кадра, таймкод, номер кадра, номер и название главы, тонкая полоса прогресса.
   Мелко, не мешает, но делает кадр «продуманным».

## Как делаем у нас (движок `scratchpad/reelfarm/kit`, GSAP)
- Сценарий: монолог 30–40 с, 2,4–2,8 слова/с, 8–13 мыслей; первая — цифра-контраст («312 просмотренных — 0 купленных»).
- Голос: лучше **живой голос владельца** (запись на телефон, лицо не нужно) — живая интонация и есть половина эффекта;
  запасной — Gemini TTS с режиссурой «монолог, самоирония».
- Каждой мысли — предмет из мира аудитории (Telegram-лента, карточка объявления, уведомление, звонок, калькулятор,
  чек-лист), а не просто слова. Текст 1–4 слова, акцентное слово — цветом.
- Переходы — морфы и перелёты элементов внутри одного холста; жёстких склеек нет.
- Счётчик-сюжет в шапке на весь ролик.
- Отличие от «Красного флага» №1 (пост + фото по сценам): там улики-фото, здесь — чистый моушн-дизайн и история.
- Для ниши перекупов цвет акцента свой (не лайм референса) — оранжевый «Перехвата» или кислотный, решает владелец.

## Проверка
Кадр 0 читается без звука; текст появляется на своём слове (±2 кадра); ни одного кадра «пустого холста» дольше 0,5 с;
мелкий моно-текст ≥ 22 px; Whisper по итоговому миксу; громкость −14 LUFS.
