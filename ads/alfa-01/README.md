# Рекламный ролик Альфа-Карты (11.10.2026)

Владелец: «видео для рекламы банковских продуктов Альфа-Банка: лучшие условия, до 50 % кэшбэка, найди условия, сделай в стилистике
банка, чтобы привлекало внимание». Вертикаль 1080×1920, 20 с, без голоса (текст + музыка/SFX, −14 LUFS), фирменные цвета банка:
красный #EF3124, белый, чёрный.

- `alfa_main.mp4` — заголовок «Лучшие условия» (как просил владелец).
- `alfa_safe.mp4` — заголовок «Выгодные условия». «Лучший» в рекламе без подтверждения — некорректное сравнение (38-ФЗ «О рекламе»,
  ст. 5 ч. 2 п. 1, ч. 3 п. 1); для публикации безопаснее этот вариант.

Сцены: «Лучшие/Выгодные условия» → Альфа-Карта, обслуживание 0 ₽ → кэшбэк до 50 % у партнёров (счётчик, монеты) → кэшбэк в категориях
на выбор → «Оформи бесплатно — по ссылке в описании». Внизу весь ролик — метка «Реклама», рекламодатель, лицензия, условия, erid.

**Условия (проверено 11.10.2026):** сайт банка напрямую не открылся (503), поэтому — по страницам alfabank.ru в поисковой выдаче и
агрегаторам: кэшбэк у партнёров до 50 % (страницы кредитной карты и «Альфа-Карта с комбо-счётом» на alfabank.ru); «бесплатная
Альфа-Карта» (промо-страница alfabank.ru/lp/retail/debit/promo/1000kb1000); категории кэшбэка на выбор (агрегаторы: mainfin.ru, banki.ru).
Агрегаторы расходятся в деталях (лимит 5 000 ₽/мес, «до 100 %» в суперкэшбэке, у одного — 590 ₽ за первый год) — перед
публикацией сверить с офером партнёрской программы.

**Перед публикацией:** вписать erid (выдаёт партнёрская программа / ОРД) в `LEGAL` в ad.html и пересобрать:
`node youtube/kit/yt/render.js ads/alfa-01/ad.html --out ads/alfa-01/out/v_main.mp4` (+ `--query v=safe --suffix safe`),
звук — `node youtube/kit/audio.js ads/alfa-01/timeline.js music.wav`, сведение — ffmpeg (см. историю коммита).
