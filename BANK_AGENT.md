# ИИ-агент для продвижения банковских продуктов

Агент сам ведёт продвижение карт по вашим партнёрским ссылкам. Стратегия и
выводы исследования рынка — в [BANK_STRATEGY.md](BANK_STRATEGY.md).

**Что агент делает каждый день:**

1. **Исследует рынок** через Claude с веб-поиском: свежие акции банков, вопросы
   людей, изменения закона о рекламе, работающие форматы. Всё складывается в
   `data/bank/knowledge_base.json`.
2. **Пересматривает стратегию** (`data/bank/strategy.md`). Смотрит на цель, темп,
   клики и оформления по каналам и продуктам и оставляет приоритеты на день.
3. **Пишет контент:**
   - посты для VK, MAX и Telegram;
   - сценарии коротких видео и статьи для Дзена.

   Факты берёт только из вашего каталога продуктов. Каждый текст проверяется на
   запрещённые обещания, выдуманный опыт, ссылки и ПСК для кредиток, а затем
   ещё раз моделью-«юристом». Не прошедшие проверку тексты переписываются.
   Маркировку «Реклама · банк · erid» и ссылку на условия добавляет код.
4. **Публикует по расписанию** (по умолчанию 09:30, 13:00, 19:30 МСК). Видео и
   статьи складывает в `data/bank/outbox/<дата>/` — их нужно выложить вручную.
5. **Консультирует в ботах** Telegram, MAX и VK круглосуточно:
   - подбирает продукт под человека;
   - честно объясняет условия;
   - даёт кнопку с партнёрской ссылкой;
   - по согласию человека напоминает через 1 и 5 дней, что сделать, чтобы банк
     засчитал оформление. На этом шаге теряется больше всего выплат.
6. **Считает переходы** по каналам и постам и учитывает оформления из кабинета
   партнёрки. Перераспределяет посты в сторону продуктов, которые приносят
   больше дохода с клика.
7. **Присылает вам отчёт:**
   - прогресс к цели (по умолчанию 100 оформлений до конца месяца);
   - сколько нужно кликов в день;
   - до какой цены клика посевы окупаются;
   - что нужно сделать вам.

**Чего агент сознательно не делает:** спам в личку и комментарии, накрутки,
выдуманные отзывы, выдачу себя за банк, рекламу без маркировки. За это банки
снимают выплаты и отключают партнёров, а ФАС штрафует. Подробности — в
стратегии.

## Что нужно подготовить (один раз)

1. **Партнёрская программа.** Например, Т-Партнёры (partners.tbank.ru), Альфа
   Партнёрс, Сбер или CPA-сеть (Pampadu, Leads.su, Affilead). Обычно нужен статус
   самозанятого. Из кабинета понадобятся:
   - партнёрская ссылка на каждый продукт;
   - **токен erid** для маркировки;
   - название параметра subid (`sub1`, `utm_content` и т. п.) — по нему агент
     поймёт, какой канал привёл клиента;
   - выплата за продукт и точное целевое действие.
2. **Площадки** (можно начать с одной):
   - **VK:**
     1. Создайте сообщество и включите в нём сообщения и «Возможности ботов».
     2. Ключ доступа сообщества с правом сообщений → `VK_GROUP_TOKEN`.
     3. Ключ пользователя-администратора с правами `wall,groups,offline`
        (через VK ID) → `VK_USER_TOKEN`. Нужен для публикации на стене.
   - **MAX:**
     1. Создайте канал.
     2. Создайте бота на платформе MAX для разработчиков (dev.max.ru) → `MAX_BOT_TOKEN`.
     3. Добавьте бота администратором канала.
     4. id канала → `MAX_CHANNEL_ID`.
   - **Telegram:**
     1. Создайте бота у @BotFather → `TELEGRAM_BOT_TOKEN`.
     2. Добавьте бота администратором канала.
     3. Адрес канала → `TELEGRAM_CHANNEL` (например `@my_cards`).
3. **Сервер (VPS) с доменом и HTTPS** для счётчика переходов, например
   `https://go.example.ru` → `BANK_TRACKER_URL`. Без сервера агент тоже работает,
   но ссылки будут вести напрямую, и клики не будут считаться. Боты тоже требуют
   постоянно включённого процесса.
4. **Ключ Anthropic API** (тот же, что для kwork-агента) → `ANTHROPIC_API_KEY`.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env            # впишите ключи (см. таблицу ниже)
python -m bank_agent init alfa-credit   # готовый каталог: кредитка Альфа-Банка по вашей ссылке FinCPA
# или: python -m bank_agent init — пустой пример, чтобы заполнить свои продукты
# проверьте в data/bank/products.json: subid_param, ставку и ПСК (см. ниже)
python -m bank_agent check      # покажет, чего не хватает (ничего не тратит)
python -m bank_agent daily      # один полный цикл; с BANK_DRY_RUN=1 ничего не публикует
python -m bank_agent report     # отчёт о движении к цели
```

Первый прогон делайте с `BANK_DRY_RUN=1` (так стоит в `.env.example`). Прочитайте
посты в базе (`data/bank/agent.sqlite`, таблица `posts`) и черновики в
`data/bank/outbox/`. Если всё устраивает, поставьте `BANK_DRY_RUN=0`.

**Постоянная работа на сервере.** Одна команда запускает всё сразу: счётчик
переходов, ботов, публикацию по расписанию, напоминания и ежедневный цикл
(по умолчанию в 07:40 МСК, `BANK_DAILY_AT`):

```bash
python -m bank_agent serve
```

Пример службы systemd (`/etc/systemd/system/bank-agent.service`):

```ini
[Unit]
Description=Bank promo AI agent
After=network-online.target

[Service]
WorkingDirectory=/opt/bank-agent
ExecStart=/usr/bin/python3 -m bank_agent serve
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Без постоянного процесса (только cron, без ботов и счётчика) запускайте цикл
утром, а публикацию — в часы выхода постов:

```cron
40 7 * * *          cd /opt/bank-agent && python3 -m bank_agent daily
31 9,13,19 * * *    cd /opt/bank-agent && python3 -m bank_agent publish
```

Счётчик слушает порт `BANK_TRACKER_PORT` (8080). Поставьте перед ним
nginx или Caddy с HTTPS на ваш домен. Например, для Caddy:
`go.example.ru { reverse_proxy 127.0.0.1:8080 }`.

## Ваши 10 минут в день

1. Прочитать отчёт агента в мессенджере. В нём темп, прогноз и пункт «Нужно от
   вас».
2. Загрузить выгрузку конверсий из кабинета партнёрки. Повторная загрузка того же
   файла безопасна:
   ```bash
   python -m bank_agent conversions export.csv
   ```
   Или написать боту `/conv 3 debit-cashback vk` — «3 оформления продукта
   debit-cashback из VK». Без этих данных агент не знает, что приносит деньги.
3. Выложить черновики видео и статей из `data/bank/outbox/<дата>/`.
4. Купить посевы, которые рекомендует агент, — только там, где клик дешевле
   окупаемого (порог есть в отчёте). Для каждого посева сделайте свою ссылку,
   чтобы агент отличал источники. Метка источника — строчная латиница и цифры:
   ```bash
   python -m bank_agent link debit-cashback tgfin1
   ```

Команды владельца в боте (id из `BANK_ADMIN_*`): `/stats` — прогресс к цели,
`/conv N продукт [канал]` — записать оформления.

## Перед запуском кредитки Альфа-Банка — сверить 2 вещи в кабинете FinCPA

Выплата уже вписана: 3 680 ₽ (поле `payout_rub`).

1. **Как называется параметр subid** в ссылках сети (раздел ссылок или
   субаккаунтов) → поле `subid_param`. Сейчас стоит `sub1`. Если в сети он
   называется иначе, ссылка всё равно работает, но в выгрузке не будет видно,
   из какого канала пришло оформление.
2. **Официальный юридический текст** (дисклеймер) из материалов оффера →
   поле `credit_disclosure`. Ставка и ПСК там сейчас взяты из открытых
   источников на 05.10.2026; в рекламе должны стоять цифры рекламодателя.

## Каталог продуктов

`data/bank/products.json` — единственный источник фактов для агента. Пример с
пояснениями — в `bank_agent/products.example.json`. Ключевые поля:

- `referral_url` — партнёрская ссылка;
- `subid_param` — параметр subid вашей партнёрки;
- `erid` — токен маркировки;
- `bank` — юрлицо банка для маркировки;
- `conditions_url` — страница с тарифами;
- `key_benefits`, `client_bonus`, `important_terms`, `restrictions` — условия;
- `target_action` — что должен сделать клиент, чтобы банк засчитал оформление;
- `payout_rub` — ваша выплата (по ней агент считает доход с клика);
- `credit_disclosure` — для кредитных продуктов: ставка и ПСК;
- `selling_notes` — как подавать продукт;
- `claim_rules` — правила текста для этого продукта: запретные фразы и
  обязательные оговорки;
- `cr_click_to_app`, `cr_app_to_conv` — свои допущения конверсии;
- `reminder_hours`, `reminder_tip` — когда и с каким советом бот напоминает об
  активации;
- `active` — включён ли продукт.

Процесс `serve` перечитывает каталог на лету, перезапуск не нужен.

## Данные и приватность

Всё хранится в `data/bank/`. Папка в `.gitignore`: там переписка с людьми,
и в репозиторий она попадать не должна. id людей и IP в статистике кликов
сохраняются только в виде солёного хеша. Пользователь бота может отписаться от
напоминаний (`/stop`) и удалить переписку (`/delete`).
