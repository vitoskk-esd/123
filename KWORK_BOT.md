# Telegram-бот «300 кворков»

Бот помогает человеку быстро подготовить много кворков для Kwork:

1. **Образцы.** После оплаты человек присылает ссылки на 3–5 своих активных кворков.
   Бот читает страницы Kwork сам: название, описание, цену, срок, рубрику и обложку
   берёт из данных страницы, без ИИ, то есть бесплатно. Если ссылки нет, можно
   вставить текст кворка. Нет своих кворков — коротко описать, что умеет.
2. **Разбор.** Claude понимает нишу и стиль продавца, цены берёт из его кворков.
3. **Сколько создать.** Кнопки 10 / 30 / 50 / 100 / 300 или «Своё число».
4. **Идеи → тексты → обложки.** Новые услуги в направлении продавца, тексты в его
   стиле. Копии образцов и дубли друг друга отсекаются, каждый текст проверяется
   по правилам Kwork.
5. **Просмотр и правки** карточками: ◀️ ▶️, «Переписать» (можно с пожеланием),
   «Обложка» (другой фон или цвет), «Цена», «Весь текст», удалить.
6. **Архив** `kwork.zip`: таблица `kworks.csv` для Excel, обложки, `listings.json` и
   инструкция «КАК_ВЫЛОЖИТЬ.txt».
7. **Оплата** через ЮKassa: 3000 ₽ разово. Владелец бота пользуется бесплатно.

## Как сделано дёшево

**Тексты.** Модели разделены по задачам:
- разбор образцов и идеи (около 7 запросов на 300 кворков) — Claude Sonnet 5.5,
  от них зависит качество всей партии;
- сами тексты (около 60 запросов по 5 кворков) — Claude Haiku 5.5, самая дешёвая модель
  ($0.10 / $0.50 за миллион токенов на входе / выходе).

Образцы продавца лежат в кэшируемой части запроса: первая пачка кладёт их в кэш,
остальные читают примерно в 10 раз дешевле. Ориентир — меньше $1 за 300 кворков.
Если качество Haiku не устроит, поставьте `KWORK_BOT_MODEL=claude-sonnet-5-5`:
тексты станут примерно в 20 раз дороже, это всё ещё несколько долларов за 300 штук.

**Обложки.** Higgsfield API рисует только 4 фона на человека (`KWORK_BOT_BACKGROUNDS`),
параллельно, примерно за 15 секунд. Модель Recraft V4.1, $0.035 за фон, то есть около $0.14
на человека. Нишу модель получает английским описанием предметов и цветов, которое Claude
пишет при разборе образцов. По-русски нельзя: картинки получаются с «каракулями» вместо
букв. Заголовок и цену на каждую из 300 обложек бот накладывает сам, бесплатно, с
затемнением под текстом. Фоны чередуются, кнопка «Обложка» переключает фон. Без ключа
Higgsfield обложки получаются градиентными — тоже бесплатно.

Проба 25.10, ниша «логотипы», по 4 фона на модель:

| Модель | Цена фона | Итог |
|---|---|---|
| Recraft V4.1 | $0.035 | чистые фоны без надписей, тёмная левая часть — **выбрана** |
| Z-Image Turbo | $0.015 | на всех 4 — русский текст «каракулями» |
| Soul 2 | $0.006 | на всех 4 — надписи; около 100 секунд на картинку |
| Soul 2 по обложке продавца | $0.006 | надписи и руки |

Модель меняется настройкой `KWORK_BOT_IMAGE_MODEL`. Цены перед запуском можно проверить
бесплатным запросом `POST https://api.higgsfield.ai/estimate/<модель>`.

## Запуск

1. Установите Python с [python.org](https://www.python.org/downloads/). На Windows
   при установке отметьте галочку «Add python.exe to PATH».
2. Скачайте проект архивом и распакуйте.
3. Дважды щёлкните **«Запуск бота (Windows).bat»** или **«Запуск бота (Mac).command»**.
   На Mac в первый раз: правая кнопка → «Открыть».
4. Мастер по очереди попросит вставить токен бота, ключ Claude и ключ Higgsfield.
   Каждый ключ он сразу проверяет бесплатным запросом и говорит, что не так. Ключ
   Higgsfield из `.env.local` подхватывается сам. Ссылка на бота для возврата после
   оплаты вписывается сама.
5. Бот запускается. Дальше тот же файл запускает его без вопросов.

Заново пройти настройку: `python -m kwork_bot setup`. Можно и вручную: скопировать
`.env.example` в `.env` и вписать ключи.

Первый, кто напишет боту `/start`, становится владельцем и получает бесплатный
доступ, поэтому напишите ему сразу после запуска. Можно и явно: вписать свой
Telegram ID в `KWORK_BOT_ADMINS`. Команда `/stats` показывает владельцу число
пользователей, оплат и кворков.

Бот работает, пока запущена команда. Чтобы он работал круглосуточно, его нужно
запустить на сервере (VPS), например через `systemd` или `screen`.

## Проверка на своём аккаунте Kwork

1. В боте: ссылки на свои кворки → «10» → посмотреть кворки → «Скачать всё архивом».
2. На своём компьютере, в папке проекта:

```bash
python -m playwright install chromium
python -m kwork_agent login              # откроется браузер — войдите в Kwork, нажмите Enter
python -m kwork_agent import kwork.zip   # кворки из бота попадут в очередь
KWORK_DRY_RUN=1 KWORK_HEADLESS=0 python -m kwork_agent publish 1
```

С `KWORK_DRY_RUN=1` агент заполнит форму, но **не отправит** кворк на модерацию.
С `KWORK_HEADLESS=0` вы увидите браузер. Скриншоты сохраняются в `data/screenshots/`.
Если форма заполняется правильно, запускайте без `KWORK_DRY_RUN=1`, начиная с 2–3 штук.

## Как подключить ЮKassa

1. **Статус.** ЮKassa работает с самозанятыми, ИП и компаниями. Самозанятость
   оформляется в приложении «Мой налог» за 10–15 минут.
2. **Регистрация.** На [yookassa.ru](https://yookassa.ru) нажмите «Подключиться»,
   заполните анкету и укажите, где будете принимать оплату (Telegram-бот).
   ЮKassa проверяет заявку, обычно за несколько дней.
3. **Ключи.** В личном кабинете: «Интеграция → Ключи API». Скопируйте `shopId` и
   секретный ключ в `.env`: `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`. В
   `KWORK_BOT_RETURN_URL` впишите ссылку на бота (`https://t.me/имя_бота`).
4. **Чеки.** Если ЮKassa должна отправлять чеки покупателям, поставьте
   `YOOKASSA_RECEIPTS=1`: бот будет спрашивать e-mail перед оплатой. Как
   оформляются чеки для самозанятых, уточните в ЮKassa при подключении.

Свой сервер для приёма уведомлений не нужен: после оплаты человек жмёт
«Я оплатил», и бот сам спрашивает статус платежа у ЮKassa.

## Важно

- **Лимит кворков на Kwork.** Kwork ограничивает число активных кворков у продавца
  и вручную модерирует каждый. Прежде чем обещать покупателям «300 кворков на
  один аккаунт», проверьте актуальный лимит в правилах Kwork.
- **Выкладка партиями.** Советуйте выкладывать 10–20 кворков в день, а не все сразу.
- **Данные пользователей** лежат в `data/bot/` (в git не попадают).
