# Telegram-бот «300 кворков»

Бот помогает человеку быстро подготовить много кворков для Kwork:

1. **Образцы.** После оплаты человек присылает **одну ссылку на свой профиль Kwork**
   (`https://kwork.ru/user/логин`) или на любой свой кворк. Бот сам берёт из профиля до 5
   кворков: название, описание, цену, срок, рубрику и обложку. Без ИИ, то есть бесплатно.
   Можно прислать и ссылки на конкретные кворки или вставить текст кворка. Нет своих
   кворков — коротко описать, что умеет.
2. **Разбор.** ИИ понимает нишу и стиль продавца, цены берёт из его кворков.
3. **Сколько создать.** Кнопки 10 / 30 / 50 / 100 / 300 или «Своё число».
4. **Идеи → тексты → обложки.** Новые услуги в направлении продавца, тексты в его
   стиле. Копии образцов и дубли друг друга отсекаются, каждый текст проверяется
   по правилам Kwork.
5. **Просмотр и правки** карточками: ◀️ ▶️, «Переписать» (можно с пожеланием),
   «Обложка» (другой фон или цвет), «Цена», «Весь текст», удалить.
6. **Архив** `kwork.zip`: таблица `kworks.csv` для Excel, обложки, `listings.json` и
   инструкция «КАК_ВЫЛОЖИТЬ.txt».
7. **Оплата** через ЮKassa: 3000 ₽ разово. Владелец бота пользуется бесплатно.

## Загрузка готовых кворков (Яндекс Диск)

Для тех, у кого тексты и фото уже готовы: кнопка **«📂 Загрузить готовые»**.

1. Бот присылает шаблон таблицы `шаблон_кворков.xlsx`. Одна строка — один кворк: фото, название,
   описание, что нужно от покупателя, цена, срок, рубрика, теги.
2. Клиент кладёт на Яндекс Диск папку: внутри папка **«фото»** и таблица (Excel или CSV).
   Открывает доступ по ссылке и присылает ссылку боту.
3. Бот скачивает всё (ключ не нужен — публичный API Диска). Фото сопоставляет со строками по
   столбцу «Фото» (имя файла), а без него — по номеру (строка 1 ↔ 1.jpg).
4. Бот проверяет каждую строку: правила Kwork (длина, нет контактов и ссылок), уникальность
   текстов и фото (между собой и с прошлыми кворками клиента), лимит 300. Что не прошло, бот
   показывает списком с номерами строк.
5. Нет цены или срока — спрашивает одну цену и один срок на все. Рубрику подбирает ИИ.
6. Есть похожие фото — клиент выбирает: **уникализировать автоматически** (мягкая обработка
   фото: кадр, оттенок, яркость, зерно) или **заменить самому** и прислать ссылку снова.
7. Готово: кворки в боте, архив `kwork.zip` для расширения.

## Расширение для выкладки (kwork_extension/)

Chrome или Яндекс Браузер, Manifest V3, работает и в Chrome 109 (последний на Windows 7).
Бот присылает его по кнопке «🧩 Расширение для выкладки».

- На kwork.ru справа внизу появляется панель: выбрать `kwork.zip`, задать «Проверять вручную
  первых N» и «Всего за запуск», пауза между кворками, кнопки «Старт», «Стоп», «Пропустить»,
  «Сначала».
- Для каждого кворка расширение открывает «Создать кворк» и заполняет все шаги:
  - шаг 1: название, раздел и подрубрика по номерам из архива, все поля рубрики («Тип», «Вид»,
    «Язык разработки», «Платформа»… — кружки и галочки, в том числе подгружаемые после выбора),
    обложка. Варианты выбирает ИИ по **настоящему дереву полей Kwork**
    (`kwork_bot/kwork_fields.json`, снимок всех 54 рубрик от 26.10: 439 полей, 2507 вариантов).
    Kwork отдаёт поля без входа в аккаунт (`/api/attribute/loadclassification`), но за частые
    запросы отвечает 403, поэтому снимок обновляется вручную: `kwork_fields.refresh_snapshot()`.
    Бот подбирает варианты при сборке `kwork.zip`, в том числе старым кворкам, и пишет их номера
    в архив (`attributes`), а расширение отмечает их по номерам. Если Kwork сменил номер, расширение
    ищет по названию поля и варианта, потом по словам (`attribute_hints`). Если для обязательного
    поля совпадения нет, выбирается «Другие» или первый вариант, и кворк ждёт проверки человеком с
    названием этого поля;
  - шаг 2: описание и «От покупателя нужно»;
  - шаг 3: цена из списка Kwork, срок и «Объём услуг в 1 кворке» (его пишет ИИ, в таблице
    Яндекс Диска — столбец «Объём услуг»; без него ИИ подберёт объём сам).
  Первые N кворков ждут, пока вы сами нажмёте «Готово» (кнопка подсвечена). Остальные
  расширение отправляет само.
- **Портфолио.** В 28 из 54 рубрик (дизайн, сайты, приложения, видео, аудио) Kwork не сохраняет
  кворк без работ в портфолио. Новому продавцу нужно 3 работы. Расширение заполняет всё остальное и
  останавливается на шаге «Портфолио»: продавец добавляет свои работы и жмёт «Готово», дальше
  выкладка идёт сама. Бот заранее пишет, сколько таких кворков в партии. В рубриках текстов
  портфолио необязательно, там расширение проходит шаг само.
- **Обновление.** Старое расширение удалить, новую папку `kwork_extension_vX.Y.Z` загрузить
  заново: если просто заменить файлы, браузер может и дальше грузить старую папку. Версия видна
  в заголовке панели. Если в браузере осталась вторая копия, панель это замечает, просит её
  удалить и не запускает выкладку. В `kwork.zip` записана нужная версия расширения
  (`kwork_meta.json`): более старое расширение просит обновиться. Архив самого расширения
  панель не принимает вместо `kwork.zip`.
- Каждый «Старт» начинается с чистой панели: журнал и ошибки прошлого запуска стираются.
- **«🖼 Заменить обложки»** — для уже созданных кворков (например, отклонённых модерацией из-за
  обложки). На странице «Мои кворки» расширение находит кворки из `kwork.zip` по названию. Адрес
  «Изменить» берётся из ссылки в карточке, иначе строится как `/edit?id=<номер>`. Расширение
  открывает каждый кворк, сверяет название (чужой кворк не трогает), закрывает окно с замечанием
  модерации, загружает новую обложку и сохраняет. Первую замену сохраняет человек, остальные
  расширение сохраняет само. Заменить можно обложки и кворков **прошлых партий**: при сборке
  `kwork.zip` бот рисует им новые обложки без цены (текст обложки ИИ подбирает по названию,
  уникальность сохраняется) и кладёт их в отдельный список `fix.json`, который заново не
  выкладывается. История партий теперь хранит кворк целиком (`id`, текст обложки, рубрику).
- «Проверять вручную первых N» — первые N **выложенных** кворков; повторный «Старт» счёт не сбрасывает
  (сбрасывает «Сначала»).
- Ошибки Kwork (поле не прошло, обложка не загрузилась, форма вернулась) останавливают
  выкладку и показываются в панели. Состояние хранится в браузере, поэтому выкладка
  продолжается после каждой перезагрузки страницы.
- Селекторы сняты с настоящей формы kwork.ru/new (25.10.2026). Проверка 25.10 (v0.1.2) шла на
  стенде: сохранённая форма, **настоящие скрипты Kwork** с его CDN и подменённые ответы сервера
  в формате из кода Kwork. Расширение работало целиком в Chromium. Сценарии «1 вручную + 2
  сами» и «3 вручную + 3 сами» на 6 кворках из 5 рубрик:
  - кворки без портфолио дошли до сохранения через собственный `/save_kwork` Kwork;
  - в запросе были все поля: название, рубрика, тип, обложка, тексты, объём, цена, срок;
  - кворки с обязательным портфолио остановились с подсказкой.

  Шаг портфолио на стенде не проверить: это Vue-компоненты, на сохранённой странице они не
  работают. На живом Kwork первые кворки стоит выкладывать в режиме ручной проверки.

## Как сделано дёшево

**Тексты пишет Gemini (Google)** — `KWORK_BOT_LLM=gemini`, модель `gemini-3.5-flash`:
- разбор образцов и идеи (несколько запросов) — с глубоким размышлением;
- сами тексты (около 60 запросов по 5 кворков) — в быстром режиме.

Gemini часто отвечает «перегружен». Тогда бот сам пробует запасные модели
(`KWORK_BOT_FALLBACK_MODELS`) и повторяет запрос с паузой. В облачной среде Claude Code
ключ Gemini уже подключён. На своём сервере нужен бесплатный ключ с aistudio.google.com
(`GEMINI_API_KEY`).

Проверка 25.10 на настоящем кворке: 5 новых кворков за 47 секунд, все прошли проверки
Kwork. Стиль и цены — как у образца.

Вернуть Claude: `KWORK_BOT_LLM=claude` и `ANTHROPIC_API_KEY` (по моей оценке, около $0.7 за 300
кворков на Haiku 5.5 и Sonnet 5.5).

**Обложки.** Higgsfield API рисует **4 общих фона на клиента** (Recraft V4.1, около $0.14).
Уникальной каждую обложку делает бесплатная обработка фона: свой фрагмент и масштаб, лёгкий
поворот, оттенок, яркость, контраст, декоративные круги, зерно. Плюс у каждой свой заголовок.
Отпечаток видимой части фона сверяется со всеми обложками партии и прошлых партий клиента.
**Цены и срока на обложке нет.** Модерация Kwork отклоняет обложку, если цена на ней расходится с
ценой кворка с учётом комиссии, а скидки на обложке запрещены. Текст для обложки чистится от цен,
процентов и скидок. Внизу обложки 3 пункта «что получит покупатель» (`cover_points`, до 30 символов,
целыми словами и грамотно: модерация проверяет орфографию). Обложки старых партий бот перерисовывает
сам при следующей сборке `kwork.zip`, а пункты для них дописывает ИИ.

**Проверка до модерации** (`kwork_bot/moderation.py`) — то, за что Kwork отклоняет кворк:
- фото клиента с Яндекс Диска: ИИ дословно переписывает текст с картинки, код ищет в нём цену,
  скидку, проценты, контакты и ссылки. Такая строка не попадает в архив, бот просит заменить фото.
  «Похоже на водяной знак» — только предупреждение: ответ ИИ здесь ненадёжен;
- ИИ-фоны: если на фоне есть надписи, он перерисовывается один раз;
- тексты: цена или скидка в названии, описании и «что нужно от покупателя» — кворк не проходит проверку.
Если похоже (отличие меньше ~10%), обработка меняется. Проверка 25.10 на 4 настоящих фонах:
300 обложек, ни одной похожей пары, все 300 файлов разные, около минуты. Кнопка «🎨 Другой
фон» бесплатно меняет обработку. Без ключа Higgsfield вместо ИИ-фонов берётся градиент,
дальше всё то же самое.

Проба 25.10, ниша «логотипы», по 4 фона на модель:

| Модель | Цена фона | Итог |
|---|---|---|
| Recraft V4.1 | $0.035 | чистые фоны без надписей, тёмная левая часть — **выбрана** |
| Z-Image Turbo | $0.015 | на всех 4 — русский текст «каракулями» |
| Soul 2 | $0.006 | на всех 4 — надписи; около 100 секунд на картинку |
| Soul 2 по обложке продавца | $0.006 | надписи и руки |

Модель меняется настройкой `KWORK_BOT_IMAGE_MODEL`. Цены перед запуском можно проверить
бесплатным запросом `POST https://api.higgsfield.ai/estimate/<модель>`.

## Запуск

1. Установите Python с [python.org](https://www.python.org/downloads/). На Windows
   при установке отметьте галочку «Add python.exe to PATH».
2. Скачайте проект архивом и распакуйте.
3. Дважды щёлкните **«Запуск бота (Windows).bat»** или **«Запуск бота (Mac).command»**.
   На Mac в первый раз: правая кнопка → «Открыть».
4. Мастер по очереди попросит вставить токен бота, ключ Gemini и ключ Higgsfield.
   Каждый ключ он сразу проверяет бесплатным запросом и говорит, что не так. Ключ
   Higgsfield из `.env.local` подхватывается сам. Ссылка на бота для возврата после
   оплаты вписывается сама.
5. Бот запускается. Дальше тот же файл запускает его без вопросов.

Заново пройти настройку: `python -m kwork_bot setup`. Можно и вручную: скопировать
`.env.example` в `.env` и вписать ключи.

Первый, кто напишет боту `/start`, становится владельцем и получает бесплатный
доступ, поэтому напишите ему сразу после запуска. Можно и явно: вписать свой
Telegram ID в `KWORK_BOT_ADMINS`. Команда `/stats` показывает владельцу число
пользователей, оплат и кворков.

Бот работает, пока запущена команда. Чтобы он работал круглосуточно, его нужно
запустить на сервере (VPS), например через `systemd` или `screen`.

## Проверка на своём аккаунте Kwork

1. В боте: ссылки на свои кворки → «10» → посмотреть кворки → «Скачать всё архивом».
2. На своём компьютере, в папке проекта:

```bash
python -m playwright install chromium
python -m kwork_agent login              # откроется браузер — войдите в Kwork, нажмите Enter
python -m kwork_agent import kwork.zip   # кворки из бота попадут в очередь
KWORK_DRY_RUN=1 KWORK_HEADLESS=0 python -m kwork_agent publish 1
```

С `KWORK_DRY_RUN=1` агент заполнит форму, но **не отправит** кворк на модерацию.
С `KWORK_HEADLESS=0` вы увидите браузер. Скриншоты сохраняются в `data/screenshots/`.
Если форма заполняется правильно, запускайте без `KWORK_DRY_RUN=1`, начиная с 2–3 штук.

## Как подключить ЮKassa

1. **Статус.** ЮKassa работает с самозанятыми, ИП и компаниями. Самозанятость
   оформляется в приложении «Мой налог» за 10–15 минут.
2. **Регистрация.** На [yookassa.ru](https://yookassa.ru) нажмите «Подключиться»,
   заполните анкету и укажите, где будете принимать оплату (Telegram-бот).
   ЮKassa проверяет заявку, обычно за несколько дней.
3. **Ключи.** В личном кабинете: «Интеграция → Ключи API». Скопируйте `shopId` и
   секретный ключ в `.env`: `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`. В
   `KWORK_BOT_RETURN_URL` впишите ссылку на бота (`https://t.me/имя_бота`).
4. **Чеки.** Если ЮKassa должна отправлять чеки покупателям, поставьте
   `YOOKASSA_RECEIPTS=1`: бот будет спрашивать e-mail перед оплатой. Как
   оформляются чеки для самозанятых, уточните в ЮKassa при подключении.

Свой сервер для приёма уведомлений не нужен: после оплаты человек жмёт
«Я оплатил», и бот сам спрашивает статус платежа у ЮKassa.

## Важно

- **Лимит кворков на Kwork.** Kwork ограничивает число активных кворков у продавца
  и вручную модерирует каждый. Прежде чем обещать покупателям «300 кворков на
  один аккаунт», проверьте актуальный лимит в правилах Kwork.
- **Выкладка партиями.** Советуйте выкладывать 10–20 кворков в день, а не все сразу.
- **Данные пользователей** лежат в `data/bot/` (в git не попадают).
