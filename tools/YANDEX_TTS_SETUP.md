# Озвучка через Yandex SpeechKit — подключение ключа

Владелец 12.10.2026: озвучку роликов переводим на Yandex SpeechKit (стартовый грант Yandex Cloud ~3 990 ₽), ElevenLabs не берём,
движок рендера не трогаем. Ключ кладёт владелец сам, **в чат ключ не присылать**.

## 1. Ключ в Yandex AI Studio

1. aistudio.yandex.ru → справа вверху **«Создать API-ключ»**.
2. Сервисный аккаунт — создать новый (например `speechkit`), если спросит.
3. Область действия (scope) — **синтез речи**: `yc.ai.speechkitTts.execute`.
4. Скопировать ключ — он показывается **один раз**.

Если при пробе будет ошибка доступа (403): Yandex Cloud → каталог `default` → **Права доступа** → сервисному аккаунту роль
`ai.speechkit-tts.user`.

## 2. Ключ в окружение Claude Code — сетевым секретом

Так же, как ключ Threads (`threads/API_SETUP.md`, шаг 7): ключ хранится вне сессии, ни я, ни скрипт его не видим —
прокси сам добавляет его к запросам в Яндекс.

Слева **New** → кнопка с облаком над полем ввода → **Cloud** → навести на окружение → шестерёнка ⚙ → **Edit environment** →
**Network secrets** → **Add secret**:

- Name: `Yandex SpeechKit`;
- Allowed websites: `tts.api.cloud.yandex.net`;
- Custom headers: Name `Authorization`, Prefix `Api-Key`, Value — ключ из шага 1.

Нажать **Connect**. Запасной вариант, если раздела Network secrets нет: переменная окружения `YANDEX_API_KEY=…`.

Секрет подхватывает **новая** сессия. После этого написать «ключ добавлен» — я сделаю пробу на 3–4 фразах (голос и амплуа —
по выбору владельца в SpeechKit Playground), ничего лишнего не тратя.
