# Бот «Бонусы банков» — воронка выплат за оформление банковских продуктов

Отдельный продукт (не связан с Арбузовым). Человек оформляет продукт банка по твоей ссылке «Приведи друга», присылает подтверждение,
ты проверяешь, что бонус за него пришёл тебе, — и бот начисляет ему твою выплату; вывод — по СБП, переводишь сам.

## Воронка
| Шаг | Что видит человек | Что пишется в статистику |
|---|---|---|
| 1. Старт | приветствие: как это работает, «до N ₽ сверху к бонусу банка» | `start` + источник из ссылки `t.me/<бот>?start=<источник>` |
| 2. Возраст | «Тебе есть 18?» — нет → вежливый отказ | `age_ok` |
| 3. Правила | карта только на себя (ст. 187 УК), выплата после подтверждения банком, согласие на данные | `consent` |
| 4. Квиз | «Где у тебя уже есть карта?» — показываем только акции, где он новый клиент; «тебе доступно N акций до X ₽» | `quiz_done` |
| 5. Каталог | кнопки акций → карточка: выплата, бонус банка, условие, срок, шаги | `offer_view` |
| 6. Ссылка | кнопка с твоей ссылкой | `click` + 3 дожима: через 1 ч, 1 день, 3 дня |
| 7. «Я оформил» | имя как в банке → 4 цифры телефона → скриншот | `claim`; тебе приходит скрин с кнопками ✅/❌ |
| 8. Одобрение | «+N ₽ на балансе» | `approved`; через сутки после заявки — напоминание про условие банка |
| 9. Вывод | «💰 Баланс» → «Вывести» → телефон СБП → банк | заявка тебе с кнопкой «💸 Выплачено» → `paid` |

Кто запустил бота, но не дошёл до квиза, через сутки получает напоминание. Нижнее меню: 🎁 Акции · 💰 Баланс · ❓ Помощь.

**Как проверять заявки.** В приложении банка в разделе «Приведи друга» видно, кто оформил по твоей ссылке и выполнил условие
(обычно имя и часть телефона). Сверяй с «Иван П. · тел …1234» в заявке и жми ✅ только после того, как бонус пришёл тебе.

## Админка (только для ADMIN_IDS)
- `/admin` — воронка по шагам с процентами, статистика по акциям (ссылки / заявки / одобрено) и по источникам, деньги.
- `/claims` — заявки на проверке; `/payouts` — заявки на вывод.
- `/broadcast текст` — рассылка всем; или ответь `/broadcast` на любое сообщение (с картинкой/кнопками) — разошлёт его копию.
- `/offers` — список акций; `/reload` — перечитать `offers.yaml` после правки (ошибка в файле не ломает бота).

## Что настроить
1. `offers.yaml` — твои акции: ссылка, выплата, условие, шаги. Сейчас там ПРИМЕРЫ с заглушками ссылок.
2. `bot/texts.py` — все тексты: название `BRAND`, контакт поддержки `HELP_CONTACT`.
3. `.env` (из `.env.example`): токен нового бота, твой Telegram id, минимальная сумма вывода, ссылка на политику данных.

## Запуск на сервере (≈15 минут)
Боту нужен сервер, который работает круглосуточно: самый дешёвый VPS у российского провайдера (1 ядро, 1 ГБ — с запасом;
обычно это несколько сотен рублей в месяц — сравни цены на сайтах провайдеров) с Ubuntu.
1. @BotFather → `/newbot` → получишь токен. Свой id узнай у @userinfobot.
2. На сервере:
   ```bash
   apt update && apt install -y python3-venv git
   useradd -m earnbot && mkdir -p /opt/earn-bot && cd /opt/earn-bot
   # скопируй сюда папку earn-bot (git clone репозитория или scp)
   python3 -m venv venv && venv/bin/pip install -r requirements.txt
   cp .env.example .env && nano .env        # токен, ADMIN_IDS, MIN_PAYOUT, PRIVACY_URL
   chown -R earnbot /opt/earn-bot
   cp deploy/earn-bot.service /etc/systemd/system/ && systemctl enable --now earn-bot
   journalctl -u earn-bot -f                # лог; Ctrl+C — выйти
   ```
3. Напиши своему боту /start (чтобы он мог присылать тебе заявки), потом `/admin`.
4. Резервная копия: база — один файл `data/bot.db`; копируй его раз в день (например, `cp` по cron в другое место).

Ссылки с источниками для рекламы: `t.me/<бот>?start=reels`, `?start=tg_post1`, `?start=threads` — в `/admin` видно, откуда люди и сколько одобрено.

## Проверено
`python -m pytest` — 9 тестов: хранилище (баланс, резерв при выводе, повторные решения, напоминания) и сквозной прогон всей воронки
через диспетчер aiogram без Telegram (старт с источником → квиз → ссылка → дожимы → заявка со скрином → одобрение → вывод → выплата,
отказ до 18, чужой человек не может одобрять). В живом Telegram бот не запускался — нужен токен нового бота.

## Риски — прочитай до запуска
- **Правила программ «Приведи друга».** Многие банки запрещают публичную рекламу реферальных ссылок и денежные стимулы за переход;
  нарушение может стоить бонусов или аккаунта. Проверь правила каждого банка, ссылки которого ставишь.
- **Дропы.** Бот, который платит за карты, привлекает перекупщиков карт. Правило «только на себя» уже в воронке; не одобряй
  подозрительные серии заявок (много заявок с похожими именами, телефон не совпадает, просят выплату на чужой номер).
- **Персональные данные.** Бот хранит имя (как в банке), 4 цифры телефона, номер для СБП. Нужна политика обработки данных
  (ссылка в `PRIVACY_URL`), согласие спрашивается на шаге правил.
- **Реклама финансовых услуг.** Посты и рассылки с продуктами банков — реклама: маркировка («Реклама», рекламодатель, erid) по закону.
- **Деньги.** Выплачивай только после того, как бонус банка пришёл тебе: сумма выплаты должна быть меньше твоего бонуса.
