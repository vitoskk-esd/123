# Synapse — сайт

Два независимых варианта лендинга для агентства автоматизации
бизнес-процессов на основе ИИ (автоматизация процессов, ИИ-презентации,
парсеры и сбор данных, боты и чат-помощники):

1. **Корень репозитория** — многостраничный статический сайт (Главная /
   Услуги / О нас / Контакты), без сборки, работает офлайн.
2. **`app/`** — одностраничный лендинг на **React 18 + TypeScript + Vite +
   Tailwind CSS + motion/react + lucide-react**, воспроизводящий кинематографичную
   тёмную эстетику (фоновое видео на весь экран, «блестящий» градиентный
   заголовок, macOS-строка меню, liquid-glass карточки) — см. `app/README.md`.
   Требует `npm install` в окружении с доступом в интернет.

Дизайн-система сгенерирована навыком `ui-ux-pro-max` (см.
`design-system/synapse/MASTER.md`) — тёмная OLED-тема с
зелёным акцентом, шрифты Gloock/Work Sans/JetBrains Mono.

## Как посмотреть

Файлы статические — сборка не нужна. Откройте `index.html` в браузере
(двойной клик) или поднимите локальный сервер из этой папки:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Структура

```
index.html         Главная
services.html       Услуги
about.html          О нас
contact.html        Контакты (форма + FAQ)
assets/css/         tailwind-lite.css (утилиты) + styles.css (токены, кастомные стили)
assets/js/main.js   Мобильное меню, аккордеон FAQ, форма, scroll-reveal
assets/fonts/       Самостоятельно хостящиеся шрифты (OFL-лицензия)
assets/logo/        Логотип Synapse (SVG + PNG, тёмный/светлый/прозрачный фон)
design-system/      Сгенерированная дизайн-система (источник правды по стилю)
```

## Логотип

`assets/logo/` содержит знак (треугольная нейросвязь трёх узлов, зелёный
акцент `#16A34A` на тёмно-синем `#0F172A`/`#020617`) и полный лого-блок со
словом «Synapse» шрифтом Gloock:

- `synapse-mark.svg` / `synapse-mark-512.png` — только знак (иконка, favicon, аватар).
- `synapse-logo-dark-bg.svg/png` — знак + текст на тёмном фоне (по умолчанию).
- `synapse-logo-light-bg.svg/png` — тёмный текст для светлого/печатного фона.
- `synapse-logo-transparent.svg/png` — без подложки, для наложения на фото/видео.

Тот же знак уже встроен инлайн-SVG в шапку и favicon всех HTML-страниц.

Сайт полностью автономен — без CDN (Tailwind/Google Fonts подключены
локально), поэтому работает офлайн и в сетях с ограниченным доступом.
