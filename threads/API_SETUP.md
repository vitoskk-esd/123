# Автопубликация в Threads — настройка (один раз, ~15 минут)

> **Статус:** подключено 09.10.2026 — аккаунт @vlad_obyzit, приложение «auto», ключ — сетевой секрет «Threads» окружения default1
> (хост graph.threads.net). Ключ действует до ~08.12.2026: за неделю ночная смена напомнит повторить шаги 5–7 (короткий ключ удобнее
> получать через `threads/token_helper.html` с адресом возврата `https://www.google.com/`), удалить старый секрет, добавить новый
> и обновить дату в `threads/token.json`. Расписание «Автопостинг Threads»: 2 раза в день, 12:35–13:15 и 19:35–20:15 МСК (случайное время).
> 09.10 вечером Meta заблокировала аккаунт («API access blocked» на любой запрос) — владелец восстановил доступ в Threads.

Посты публикует скрипт `tools/threads_publish.py` через **официальный Threads API**. Логин и пароль не нужны и никуда
не передаются, нужен только ключ доступа. Ключ ты кладёшь сам в секреты окружения Claude Code. **В чат ключ не присылай.**

Сайт Meta для разработчиков из России может открываться только через VPN.

## Шаги

1. **Аккаунт разработчика.** Открой https://developers.facebook.com и войди своим аккаунтом Meta (Facebook). Если попросит,
   подтверди телефон и прими условия: это бесплатно.
2. **Приложение.** My Apps → Create App → вариант использования **Access the Threads API** → любое название (например,
   «Бонусы автопостинг») → Create.
3. **Разрешения.** В приложении: Use cases → Threads API → Customize (Настроить). Включи **threads_basic** и
   **threads_content_publish**.
4. **Ты — тестировщик.** App roles → Roles → Add People → **Threads Tester** → впиши свой ник в Threads.
   Затем в Threads: Настройки → Аккаунт → **Разрешения для сайтов** → **Приглашения** → прими приглашение.
   Без этого будет ошибка «user has not accepted the invite».
5. **Короткий ключ (1 час).** Tools → **Graph API Explorer** → справа выбери своё приложение → в выпадающем списке вместо
   `facebook` выбери **threads.net** → **Generate Threads Access Token** → разреши доступ. Скопируй ключ.
6. **Долгий ключ (60 дней).** В приложении: App settings → Basic → **Threads App Secret** (у Threads свой ID и секрет).
   Вставь в адресную строку браузера свой секрет и короткий ключ вместо слов в скобках и открой:
   ```
   https://graph.threads.net/access_token?grant_type=th_exchange_token&client_secret=(СЕКРЕТ)&access_token=(КОРОТКИЙ_КЛЮЧ)
   ```
   Ответ — `{"access_token":"…","token_type":"bearer","expires_in":5184000}`. Скопируй значение `access_token`.
7. **Положи ключ в окружение — сетевым секретом.** Тогда ключ хранится вне сессии, и ни я, ни скрипт его не видим.
   В Claude Code слева нажми **New**, затем кнопку с облаком **default1** над полем ввода → **Cloud** → наведи на **default1**
   → шестерёнка ⚙ → окно **Edit environment** → **Network secrets** → **Add secret**:
   - Credential type: **Bearer**;
   - Name: `Threads`;
   - Allowed websites: `graph.threads.net`;
   - Custom headers: Name `Authorization`, Prefix `Bearer`, Value — ключ из шага 6.

   Нажми **Connect**. Запасной вариант, если раздела Network secrets нет: переменная окружения `THREADS_ACCESS_TOKEN=…`.
8. Напиши мне **«ключ добавлен»**. Я проверю ключ (аккаунт и лимит, **ничего не публикуя**) и включу расписание.

## Как будет работать

- **Пакет постов.** Ночная смена кладёт пакет на завтра в `threads/queue.json`: 2 поста с временем по Москве
  (12:30, 19:30; публикуются со случайной задержкой до 40 минут). В утреннем сообщении — список постов с временем.
- **Можно поправить.** До времени публикации любой пост можно убрать или изменить: напиши «убери пост 3» или «замени текст
  поста 2 на …».
- **Публикация.** В каждое время запускается расписание и публикует **один** пост, время которого пришло. Ссылка на пост
  записывается в очередь.
- **Проверка текста.** Скрипт не пропустит пост длиннее 500 символов или со ссылкой (закон о рекламе на ресурсах Meta) —
  такой пост помечается `rejected`.
- **Продление ключа.** Ключ — сетевой секрет, скрипт его не видит и продлить не может: дата выдачи — в `threads/token.json`,
  за неделю до конца срока ночная смена напомнит повторить шаги 5–7 (раз в 2 месяца, 2 минуты).
- **Ответы.** Комментарии к чужим постам API не публикует, их ты по-прежнему вставляешь сам.

## Остановить

Напиши «выключи автопостинг»: я отключу расписание. Или удали секрет `THREADS_ACCESS_TOKEN` — тогда скрипт ничего не будет
публиковать.
