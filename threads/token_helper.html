Ключ Threads для автопостинга

Запасной способ, если Graph API Explorer показывает белый экран. Всё происходит между твоим браузером и Meta.

0. Один раз: адрес возврата

В приложении: Сценарии использования → Threads API → Настроить → Настройки. В полях «URL-адреса обратного вызова для перенаправления», «URL обратного вызова для удаления» и «URL обратного вызова для отмены установки» впиши https://example.com/ и сохрани. Там же возьми ID приложения Threads и секрет приложения Threads.

1. Разрешить доступ

Нажми «Разрешить». Откроется страница example.com, а в адресной строке будет https://example.com/?code=AQB…#_. Скопируй всё после code= до #_ (сами #_ не копируй).

2. Короткий ключ (1 час)

Откроется вкладка с ответом {"access_token":"TH…","user_id":…}. Скопируй значение access_token.

3. Долгий ключ (60 дней)

Ответ: {"access_token":"TH…","token_type":"bearer","expires_in":5184000}. Значение access_token положи в окружение Claude Code как THREADS_ACCESS_TOKEN (меню окружения в заголовке сессии → Edit). В чат ключ не присылай. После этого закрой вкладки с ответами.
