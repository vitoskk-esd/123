# Референс 2 — Fomobase (Лео Бруни), «Я проверил ВСЕ способы заработка на FunPay: тир-лист 2026»

https://youtube.com/watch?v=WfKhwnwlTAU · 6:55 · 17.1k просмотров · 283 лайка · 12 комм.
Опубликован 2026-09-11. Формат: **тир-лист** (D → C → B → A → S), закадровый голос +
2D/AI-аватар ведущего. В описании дисклеймер: «показанное создано ИИ и является постановочным».

## Хук (0:00–0:20) — формула

1. Заявка: «Я проверил абсолютно все … и составил ультимативный тир-лист».
2. Критерии оценки (3 шт.): вложения, время, сложность — показаны карточкой.
3. Шкала: «от мусора до реальных денег».
4. Имя → «и мы начинаем».

Картинка: текст по словам на чёрном фоне со свечением → **заблюренный тир-лист**
в 3D-наклоне (интрига: что в топе — узнаешь в конце) → карточка критериев → аватар.

## Шаблон каждого пункта (повторяется ~10 раз)

Заставка уровня (чёрный фон + крупная буква + неон уровня, саб-удар) →
тир-лист с наездом на текущий уровень → название способа крупно →
перебивка «ЧТО НУЖНО ДЕЛАТЬ?» на чёрном → механика (B-roll) → минусы/риски для
новичка → вывод одной фразой («продаёте лопаты во время золотой лихорадки»).

## Приёмы удержания

- **Иерархия снизу вверх**: лучшее — в конце, зритель досматривает ради S.
- **Заблюренный итоговый тир-лист** в хуке = открытая петля на весь ролик.
- **Средний CTA-игра** (4:50): бабл-счётчик «500 👍» — «наберём 500 лайков —
  при вас создам магазин с нуля».
- **Итог-рецепт**: «нет денег — начинай с C; цель — последние два уровня».
- **Финал**: TG «даю ещё больше закрытой инфы бесплатно» + вопрос в комментарии
  «какой способ пробовали и сколько удалось поднять».

## Монтаж (повторяющееся)

- B-roll «для дофамина»: динамичный геймплей (гонки) под разговорные куски.
- 3D-наклон скриншотов сайта/телефона, плавающие 3D-иконки (карты, кошельки, логотипы).
- Перебивки текстом на чёрном («ЧТО ДЕЛАТЬ?») — микропауза между мыслями.
- Инфографика-схема для сложного пункта (шаги 1-2-3-4 стрелками).
- Сплит-скрин 50/50 для сравнения.
- Звук: голос с радио-компрессией; саб-дроп на каждом повышении уровня;
  swoosh на каждом появлении текста; бит ускоряется к кульминации (S).
- Средняя длина кадра 1,5–2,5 с; темп речи ~174 сл/мин (быстрее, чем у №1).
