## Что общее (это и есть «стиль владельца»)

1. **Без лица в кадре.** Только закадровый голос — уверенный, быстрый, без пауз.
   У №2 — статичный 2D/AI-аватар ведущего как «якорь» между блоками.
2. **Тёмный фон + анимированная сетка** (ретро/неон), контент — в окне-карточке
   со скруглёнными углами и свечением поверх фона. Почти никогда не на весь экран.
3. **Смена картинки каждые 1,5–3 с**: склейка, зум, новый мем, всплывающая плашка.
4. **Крупный жирный текст с цветовым кодом**: белый — основа, зелёный — деньги/успех,
   красный — ошибки/запреты. У №2 каждый уровень тир-листа — свой неон
   (D красный → C оранжевый → B жёлтый → A синий → S фиолетовый).
5. **Звук**: тёмный электронный бит под всем роликом; whoosh на каждой смене,
   pop на тексте, касса на цифрах, звуки интерфейса (тап, отправка в TG),
   саб-удар на смене раздела.
6. **Иллюстрации**: мемы-реакции на 1–2 с, скринкасты телефона/сайта в мокапе
   (часто в 3D-наклоне), стоки, иконки платформ, стрелки и обводки.
7. **Структура**: хук 20–35 с → разделы по нарастающей ценности → открытые петли
   («расскажу чуть позже») каждые 1,5–2 мин → средний CTA → итог из 3 пунктов →
   подписка + Telegram «за тем, что не попало в видео».

## Чего не переносим

- Слова «схема», «без вложений», «лёгкие деньги» в названии и речи — для нашей
  ниши (банки, карты) это читается как мошенничество (см. reel-production §1b).
- Кадры из фильмов, мультфильмов и чужой геймплей — риск Content ID и отказа
  в монетизации. Мемы-реакции делаем свои (код/ИИ-картинки/стикеры).
- Байт «500 лайков — и я сделаю…» — допустим, только если обещание реально выполним.
