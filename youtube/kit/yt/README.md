# YouTube-движок «режимы» (`youtube/kit/yt/`)

Ролик = таймлайн из отрезков; каждый отрезок показан одним из 9 режимов, выбранных владельцем 09.10
(`reels/lab/engine-roadmap.md`, «Набор режимов»). Без 3D (владелец: «3д убери»). «Студия» (`kit/studio.js`) — только для рилсов.

| Файл | Что |
|---|---|
| `yt.js`, `yt.css` | ядро: `YT.play({size, foot, chapters, segs})`, переходы, подпись главы, плашка, зерно, проверка ритма `YT.lint` |
| `modes/office.js` | «Ночной офис»: мир-стол, камера по кадрам, моушн-блюр по скорости, глубина резкости; предметы doc / phone / ledger / card / mon / sticky |
| `modes/editorial.js` | «Журнальная инфографика»: метка, заголовок по словам, столбики (`bars`) или крупные числа (`stats`), источник |
| `modes/phone.js` | «Телефон крупно»: экраны promo / order / stats / html, пуши, нажатие (круг, палец по желанию), малая ГРИП |
| `modes/board.js` | «Маркерная доска»: линии рисуются, надписи «пишутся», камера по `focus` |
| `modes/search.js` | «Поиск»: запрос печатается, подсказки, ответ по словам |
| `modes/scrap.js` | «Коллаж-скрапбук»: вырезки, скотч, стикеры, стрелки, подписи от руки — каждое «шлёпается» в свой момент |
| `modes/swipe.js` | «Свайп-карточки»: ДА / НЕТ, карточки улетают, «мэтч» — правило главы |
| `modes/voice.js` | «Голосовое сообщение»: «записывает…», волна закрашивается, расшифровка по словам |
| `modes/ai.js` | «ИИ-ассистент»: вопрос, «думает», ответ печатается по словам, крупный итог `.big` |
| `demo.html` | демо: начало ролика №3 + фрагменты глав 1–4, все режимы и переходы (69 с) |
| `render.js` | `node render.js demo.html --query label=1 --stills 4.5,22.2` (кадры) / `--out out/demo.mp4` (видео) |

Отрезок: `{mode, t0, t1, data, tin: {type, dur, at, key}, marks: {ключ: селектор}}`. Все времена в `data` — от начала отрезка.
Переходы (`tin` входящего отрезка): `flash` — засветка (по центру границы), `zoom` — пролёт сквозь точку `at` (экран
телефона/монитора), `match` — склейка по предмету: элемент с `data-match=key` (или `marks`) в новом слое «садится» из
положения такого же элемента в конце прошлого, `cut` — просто склейка. `?label=1` — подпись режима и времени (для каруселей).

Правила ритма (`YT.lint`, предупреждения в консоли и `window.YT_LINT`): один режим не дольше 90 с подряд, «Ночной офис» —
не больше 2 отрезков, отрезок не короче 2 с, без разрывов. Рендер детерминированный (анимация — функция от t).
