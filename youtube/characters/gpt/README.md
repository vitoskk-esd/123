# Картинки из ChatGPT (владелец 15.10)
Владелец генерирует вручную в ChatGPT по нашим промптам (Google/OpenAI API из России не оплачиваются, Яндекс — «не используем»).
Стиль одобрен: «тёплая детальная иллюстрация» (test_kitchen_with_arbuzov.jpg — первая проба с Арбузовым по образцу avatar.png).
- bg/ — фоны без персонажей, 1672×941 (16:9): kitchen, bank, store, room.
- sprites/ — Арбузов отдельно на пурпурном фоне #FF00FF (позы × рот открыт/закрыт) — ждём от владельца.
Схема: фон оживляем камерой и влётом предметов (кодом), Арбузова вырезаем и ставим поверх, рот — смена спрайтов под голос,
цифры/пуши/субтитры — кодом. Для рилсов нужны вертикальные (9:16) версии фонов.
